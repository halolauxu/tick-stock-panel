# P0 沪深主板微盘时间序列状态：全历史发现合同

冻结日期：2026-09-02

## 假说

微盘收益可能在周频存在两类可交易结构：拥挤资金延续，或流动性冲击后的短期反转。
本研究只使用已经完成并可结算的微盘周收益决定下一周是否持仓，不使用当周尚未发生
的收益，不改变微盘选股和执行规则。

这是已知全历史后的机制发现，不是独立验证。

## 固定候选

初始预热不足时持有现金；其余时间只运行四个互斥定义，不枚举窗口和阈值：

1. `previous_week_reversal`：上一已完成周收益不大于 0 时持有微盘；
2. `previous_week_momentum`：上一已完成周收益大于 0 时持有微盘；
3. `four_week_reversal`：过去四个已完成周复合收益不大于 0 时持有微盘；
4. `four_week_momentum`：过去四个已完成周复合收益大于 0 时持有微盘。

未持有时现金收益按 0。每个当周收益必须等到退出日以后才能成为后续信号输入。

## 门槛

2026-01-01 至 2026-08-28 收益大于 30%，2014–2025 每年收益均大于 0，最大
回撤不差于裸微盘。满足者才进入统一现金账户确认和至少 60 个交易日前向模拟。
