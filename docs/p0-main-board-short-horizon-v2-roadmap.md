## 1. 使用规则

本文件是后续研究的唯一主索引。每次研究必须先定位到一个步骤 ID，再开始取数、
实现或回测；没有步骤 ID 的临时试验不得进入正式结论。

1. 同一时间最多一个步骤为 `IN_PROGRESS`。
2. 前置步骤未完成时，后续步骤不得开始。
3. 每个步骤先冻结输入、规则、输出和门槛，再读取该步骤收益。
4. `REJECTED` 的规则不得换参数复活；新假设必须新增步骤 ID 和合同。
5. 原始结果只追加、不覆盖；总表只记录结果路径、哈希、裁决和下一步。
6. 工程跑通、页面可见、测试通过和历史收益分别记录，不能相互替代。
7. 任何数据缺口必须标记 `BLOCKED_DATA`，不得使用今天的数据回填历史点时状态。

允许状态：`NOT_STARTED`、`IN_PROGRESS`、`BLOCKED_DATA`、`REJECTED`、
`SKIPPED_DEPENDENCY`、`PASSED`、`COMPLETE`。

## 5. 明确禁止重跑的路线

| 已失败路线 | 禁止事项 | 原因 |
|---|---|---|
| 全风险关闭即清仓 | 不调风险阈值、不延长关闭期 | 收益和回撤同时失败，并且不符合跌停/停牌退出现实 |
| 质量 + 60日动量 | 不改权重、窗口、持仓数复活 | 损失微盘收益且恶化尾部 |
| 解禁供给风险 | 不围绕 5%、20日等阈值微调 | 不同危机年份方向不稳定，退出能力下降 |
| 融资去杠杆 | 不放宽条件增加触发 | 信号稀疏且滞后，没有修复危机 |
| 通用行业20日动量 | 不作为行业页面直接买入规则 | 开发期收益和回撤均失败 |
| 无边界 AI 参数搜索 | 不让模型读取压力期后反推参数 | 无法区分机制与过拟合，且浪费预算 |

## 7. DeepSeek 与数据预算

- 微盘归因、M1/M2/M3、账户计算均不调用 DeepSeek。
- DeepSeek 只用于无法用确定性字段完成的公告/PDF事实抽取与矛盾检查。
- 缓存键必须包含 PDF 哈希、模型、提示词版本和输出 schema；命中缓存不得再次付费。
- 总费用硬上限 60 元：事实抽取 35 元、交叉核验 15 元、异常重试 10 元。
- 分钟与竞价只使用现有一年数据，不启动无边界历史扩采。
