## 结论

**DATA_GAP，结果前终止。** 2012–2020 的 108 个月分区全部存在，84,074 条
分红送转公告没有重复键或非法行，税前、税后每股现金分红字段也已按供应商语义
重新采集。但可作为首次点时信号的年度现金分红 `预案` 几乎全部集中在
2019–2020，无法覆盖冻结的 2014–2020 开发期。价格、基准和未来收益均未读取，
严格策略计数保持 `0/5`。

## 研究裁决

1. 不用 `实施`、`股东大会通过` 或除权日倒推首次预案日；
2. 不把 2019–2020 两年样本扩写成 2014–2020 开发证据；
3. 不降低“每个开发年份都有预案样本”的冻结门槛；
4. 当前现金分红增长机制不读取价格，不产生收益数字；
5. 未来只有获得覆盖 2014–2018 的原始首次预案公告时间后，才可注册新的数据版本。
