## 为什么低回撤不能直接采纳

1. 20 万账户计划把约 18.27%的资金放入 20 只股票，单只目标不足 2,000 元；
   100 股整手使大量候选在风险预算内无法购买；
2. 动态账户平均只持有 13.66%实际仓位，回撤改善有相当部分来自未能投入计划资金，
   不是纯粹的波动率预测价值；
3. 卖出失败主要来自历史行情缺失和长期停牌重试。虽然期末最终清零且现金账一致，
   但不能把后来卖出成功倒算为计划日可成交；
4. 固定 20%对照同样只有 65.97%卖出成交率，所以更简单的限仓政策也尚未形成
   可部署账户。

## 后续边界

1. 不读取本分支的验证期和压力期，不修改 20 日、6%或 20%常数；
2. 不把 20 只改成 5/10 只后沿用本次计数；更少持仓属于新的集中度机制，必须重新
   冻结且会增加个股尾部风险；
3. 不因 50 万以上买入率改善而提高基础预算，卖出执行仍未通过；
4. 微盘继续只保留为“有正收益但缺乏可接受尾部与小账户执行方案”的研究证据；
5. 严格达标策略数维持 `0 / 5`。
