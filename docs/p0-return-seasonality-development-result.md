## 投资结论

同月收益季节性没有转化为可投资的 A 股长多账户。20 万元账户在 2013-10-08 至
2020-12-31 的年化净收益为 **-0.45%**，累计亏损 **-3.15%**，最大回撤
**-64.62%**；同期全 A 点时等权基准年化 **+13.30%**，策略年化超额为
**-13.76 个百分点**。

“过去 5 年其他月份赢家”对照年化为 -2.31%，同月信号只改善 +1.86 个百分点，远低于
冻结的 +10 个百分点独立增量门槛。30、50、100 万元账户年化分别为 +0.26%、
+0.06%、+0.18%，资金档位变化没有暴露任何接近 50% 的隐藏收益。

开发期规则在 2015 年获得 +81.66%，但 2016–2018 连续三年分别亏损 -22.73%、
-22.10%、-25.13%，2020 年再次亏损 -6.63%。这是强烈依赖个别市场年份、长期承受
巨大回撤的暴露，不是稳定的同月季节性 Alpha。整个家族按冻结合同终止，不缩短形成期、
不挑选有利月份，也不读取后续样本续命。

## 数据修复与可审计边界

- 首次开发试跑暴露出 2013-01 至 2013-08 形成期缺口，导致 2014-2018 被错误空置；
  该次结果被撤销，没有用于策略裁决；
- 补采后预热数据覆盖 2007-12 至 2013-08 的 69 / 69 个月，随后按原冻结规则重跑；
- 最终账户包含 2014-2020 七个完整年度，2021 年后的验证与压力数据均未读取；
- 最终形成 5,674 条同月候选记录、覆盖 1,445 只股票，账户按 88 个真实月度调仓日执行；
- 复用统一的点时股票池、历史股本和名称、100 股整手、T+1、费用、滑点、涨跌停、
  停牌、成交额容量、陈旧估值和资金对账。
