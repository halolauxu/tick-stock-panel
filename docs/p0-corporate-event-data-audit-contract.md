# P0-D 公司事件与交易事件数据审计合同

状态：冻结

冻结日期：2026-08-30

目标：在继续日线技术规则搜索前，优先检查六类具有独立经济含义、带明确事件日期的数据源，建立下一轮事件级研究队列。数据可取不等于策略有效，不计入年化 50% 策略数量。

## 1. 预注册数据源与机制

| 数据源 | 事件时钟 | 待验证机制 |
| --- | --- | --- |
| `forecast` 业绩预告 | 公告日后下一交易日 | 超预期盈利改善后的信息缓慢吸收 |
| `repurchase` 股票回购 | 公告日后下一交易日 | 公司以现金表达低估信号，实施进度区别于方案公告 |
| `stk_holdertrade` 股东增减持 | 公告日后下一交易日 | 内部人资金承诺或供给压力 |
| `top_list` 龙虎榜 | 上榜交易日收盘后 | 公开注意力与资金结构的延续或反转 |
| `block_trade` 大宗交易 | 成交交易日收盘后 | 大额折溢价交易传递的知情交易或供给压力 |
| `share_float` 限售解禁 | 公告日与解禁日 | 可预知流通盘供给冲击及事件后的错定价修复 |

上述六类只是研究入口；同一事件的阈值或持有期变体不能重复计数。所有信号最早在事件日收盘后形成，最早使用下一交易日真实开盘价成交。

## 2. 审计方法

- 只使用服务器已有 Tushare 配置，不输出令牌；
- 在 2019、2024、2026 三个相隔时期分别抽样，区分“接口有权限”“指定月份无事件”和“接口报错”；
- 输出行数、唯一股票数、事件日期范围、关键字段缺失率和接口上限命中情况；
- 不把一次成功请求冒充全历史已落盘；通过后再按年度分区采集并做去重、点时与行情连接审计；
- 任何接口没有权限时记录为数据阻断，不使用当前快照或新闻搜索回填历史。

## 3. 进入事件研究的最低门槛

- 至少覆盖 2019、2024、2026 三个抽样期中的两个；
- 有明确的公告日或交易日，能够保守映射到下一交易日；
- 关键方向字段可用，例如预告类型与变动区间、回购进度、增减持方向、龙虎榜净买额、大宗成交价、解禁比例；
- 样本量足以拆分开发期、独立验证期和压力期；
- 与现有日线和点时证券主数据可以按 `symbol + date` 连接。

通过审计后，优先选择经济机制清晰、事件数量充分且不依赖当前快照的一类，先冻结事件研究合同，再采集全历史。没有通过审计的数据源不得进入参数搜索。
