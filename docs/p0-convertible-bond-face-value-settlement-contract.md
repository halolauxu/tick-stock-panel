# P0 可转债双低：面值回收下界合同

状态：冻结

冻结日期：2026-09-02

## 1. 为什么零回收不是最终经济口径

零回收研究证明旧双低结果不能把退市前最后价格无限延续，但它只是最悲观的账务
下界。上交所投资者教育明确说明，有条件强制赎回通常按债券面值加应计利息赎回
未转股可转债；深交所历史公告中汽模转债实际赎回价为 100.31 元/张，康弘转债
为 100.29 元/张。

本项目开发期发生清算的 20 只债券均满足：实际退市日早于合同到期日，主表最终
剩余规模为 0。被动持有人未主动卖出或转股时，按 0 元核销会抹掉其合同赎回权；
继续按退市前二级市场价格估值又会高估。面值 100 元是两者之间可审计的保守下界。

官方依据：

- 上交所投资者教育：<https://edu.sse.com.cn/service/hotline/qa/c/5151728.shtml>
- 汽模转债赎回公告：<https://disc.static.szse.cn/disc/disk01/finalpage/2017-08-03/b47fada4-1aa4-4147-97f6-33224916af88.PDF>
- 康弘转债赎回风险公告：<https://disc.static.szse.cn/download/disc/disk02/finalpage/2020-10-13/0cc30195-b355-4754-8541-2dadd7cc58b3.PDF>

## 2. 唯一结算变化

完全复用已冻结的双低规则、候选、周频、交易时钟、10 张整数手、费用、滑点、
容量、停牌、涨跌停和四档资金。只替换退市后的账务结算：

- 退市日仍先尝试真实市场卖出；没有可靠行情则不制造成交；
- 在退市后的第一个账户动作日，若该债实际早于到期日退市且最终剩余规模为 0，
  每张按 **100 元**现金回收；
- 不计应计利息，不按退市前收盘价回收，不假设主动转股后的股票价值；
- 事件记为 `CB_DELISTED_FACE_VALUE_RECOVERY`，不是市场卖单，不收交易佣金；
- 100 元是固定面值，不按结果调整，不逐券选择较高的转股价值或公告赎回价。

股票和其他资产的退市核销默认仍为 0；新增参数默认值必须保持 0，不能改变现有
研究结果。

## 3. 研究顺序和门槛

开发期仍为 2017-01-01 至 2020-12-31。20/30/50/100 万元分别独立运行；20 万元
为主账户。开发账户必须同时满足：

- 年化净收益不低于 15%；
- 相对同期可交易转债等权基准年化超额不低于 5 个百分点；
- 最大回撤不超过 25%；
- 四年至少三年为正收益；
- 买入和卖出成交率分别不低于 90%；
- 期末没有未解决持仓，现金账最大误差不超过 0.01 元。

开发期通过前不得运行或读取 2021 年以后的验证与压力收益。通过也只获得建立逐券
官方赎回账本并运行独立验证的资格；面值下界本身不能直接进入模拟盘。
