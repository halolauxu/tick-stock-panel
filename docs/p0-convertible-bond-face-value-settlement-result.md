# P0 可转债双低：面值回收下界结果

运行日期：2026-09-02

## 裁决

**终止，不读取独立验证和压力期。** 每张提前退市转债按 100 元面值回收后，
20 万元账户年化净收益为 **+9.93%**、最大回撤为 **-23.91%**。风险门槛通过，
但收益仅比同期可交易转债等权基准高 **1.09 个百分点**，四年只有两年盈利，卖出
成交率只有 **84.98%**。

这证明零回收确实过度悲观，但也证明旧双低的 +17.57%不能恢复为符合门槛的
可投资收益。面值结算已经把合同权利纳入账户，失败不再来自退市资产按零核销。

## 结算与容量证据

- 20 万账户实际发生 20 次 `CB_DELISTED_FACE_VALUE_RECOVERY`；
- 每张固定回收 100 元，不含应计利息，不使用退市前二级市场高价，不假设主动转股；
- 期末没有未解决持仓，四档现金账误差均为 0；
- 20 万账户买入容量尚可，但卖出受容量、停牌和缺失行情影响，成交率低于 90%；
- 从 30 万开始卖出成交率降至 75.27%，100 万仅 34.86%，该规则的容量上限明显
  低于目标资金扩展路径。

## 最终含义

双低策略在正确结算下是一个约 8%–10%年化、20%–26%回撤、容量受限的普通债券
轮动，不是 15%以上的低相关第二引擎。逐券补齐 0.2–0.5 元左右的应计利息不会填补
与 15%收益门槛、5 个百分点超额门槛和 90%卖出执行率之间的缺口，因此不再继续
采集逐券赎回价以“抬高”开发结果。
