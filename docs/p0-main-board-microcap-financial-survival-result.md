## 冻结过滤与候选漏斗

在每周裸主板微盘最小十分位中，只保留归母净利润和经营现金流为正、资产和权益为
正、负债率不高于70%、商誉占资产不高于20%的证券，再按点时市值选择最小20只。

2014–2020开发期共有359个调仓日。裸微盘候选82,078条，质量过滤后42,872条；
355个调仓日存在合格证券，其中348日不少于20只，平均每次120.77只。过滤不是因为
样本太少而失败，而是经济效果没有满足冻结目标。

## 为什么直接终止

20万元主账户同时失败于收益增量、回撤改善、正收益年度数、卖出执行率和期末退出
完整性五道门。资金从20万增加到100万没有改变结论：年化没有继续提高，卖出容量
反而更差。开发失败后，验证期和已知压力期保持未读，不能为了命中2026目标再修改
负债率、商誉率、财务年龄或只保留事后有效条件；整个静态财务生存过滤家族终止。
