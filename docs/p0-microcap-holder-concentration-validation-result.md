# P0 微盘 × 筹码集中：独立联合验证结果

结论：**终止，不计入年化 50%策略目标。**

- 2021–2023 共形成 4,706 个股东户数收缩事件，其中 289 个发生在点时市值最小 10%；
- 160 个事件通过统一股票池并全部可交易，覆盖 98 个独立公告日；基准覆盖率、2 万元容量可行率均为 100%，未解决退出为 0；
- 20 日平均净收益 +3.414%，平均超额 +3.836%，超额日聚类 t 值 3.57；3/3 年平均超额为正，单年最大正贡献占比 56.66%；
- 失败项：平均净收益低于冻结的 4%门槛，公告日少于 100 个门槛；2022 年平均绝对收益为 -0.32%。

联合筛选明显提高了单独筹码集中事件的相对收益，但事件稀疏且绝对收益不足。以约 53 个事件/年、每笔 2 万元粗略计算，其对 20 万账户的未复用资金贡献远低于 50%目标；不因接近门槛而放宽规则。
