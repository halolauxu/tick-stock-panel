# P0 指数调入强制资金流数据合同

冻结时间：2026-08-31。严格策略计数仍为 `0/5`。

## 机制与方向

指数公司公布定期调样后，跟踪指数的被动资金必须在生效日前后买入新调入成分。
冻结方向为：公告后买入沪深 300 / 中证 500 的新调入股票，在正式生效窗口退出，
捕捉可预见的强制需求。该机制的交易对手、信息时钟和持有期均不同于微盘、价格
动量、涨停情绪和 ETF 份额流。

当前步骤只构建成分变更元数据，不读取个股价格、收益或基准收益。

## 冻结元数据范围

- 指数：`000300.SH`（沪深 300）、`000905.SH`（中证 500）；
- 区间：2013-01-01 至 2020-12-31；
- 来源：Tushare `index_weight`，原始来源为指数公司公开数据；
- 逐月保存完整成分及权重，保留退市和后来调出证券；
- 定期调样候选只比较每年 5→6 月、11→12 月快照的新增成分；
- 产物不得包含个股价格或未来收益。

## 结果前门槛

- 两个指数均存在，月度覆盖率各不低于 95%；
- 每个指数至少 12 个可比较的半年调样周期；
- 两指数合计至少 500 条调入记录；
- 成分代码、快照日期、权重合法且唯一。

数据门通过后仍不能看价格。每个周期必须进一步与中证指数/交易所官方公告逐期
核对公告日、生效日、调入名单及数量；无法匹配的周期整期剔除，不能用月末成分
倒填成公告时已知信息。官方核对完成后，先冻结成交时点、持有期、容量和账户门槛，
再打开开发集价格。

数据可用或开发集通过都不计入最终 `5` 个策略；仍需独立验证、压力期、四档容量和
至少 60 个交易日前向模拟。
