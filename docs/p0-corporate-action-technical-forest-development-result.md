# P0 公司行动公告池 × 技术状态随机森林：开发期结果

运行日期：2026-08-31。冻结合同见
[开发期合同](p0-corporate-action-technical-forest-contract.md)。本结果只读取 2014–2020
公告与价格；2021 年以后独立验证和压力期均未读取。

## 裁决

**整个“公司行动公告池 × 技术状态机器学习”家族终止，严格达标计数仍为
`0/5`。**

20 万元主账户年化净收益 `-3.86%`、累计收益 `-20.42%`、最大回撤
`-70.08%`。同期全 A 点时等权基准年化 `+13.54%`，候选落后 `17.40` 个百分点；
同公告池、不使用机器学习的事件时间对照年化 `-2.28%`，随机森林反而落后
`1.58` 个百分点。开发期已经失败，因此不调整模型、特征、训练窗口、持仓数或
成交时钟，也不读取验证期续命。

模型在横截面上只有弱排序能力，而且该弱信号没有转化成账户增量：机器学习账户比
事件时间对照更差。这不是“手续费把一个 50% 毛策略打没了”。把 20 万账户全部
`74,309` 元费用与滑点机械加回期末权益，忽略路径和仓位变化，得到的宽松上界年化
也只有约 `+2.71%`。

公告语义、无未来标签、A 股 T+1、涨跌停、停牌、整手、最低佣金、印花税、双边

边界保留，而不是继续搜索同类森林参数。
