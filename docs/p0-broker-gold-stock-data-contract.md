# P0 券商月度金股共识：点时数据合同

冻结日期：2026-08-31

## 研究问题

不同券商在同一月独立把同一只股票列为“月度金股”，可能代表卖方研究共识与
机构注意力集中；若信息没有在名单发布时完全反映，后续一个月可能出现价格漂移。
这是月频卖方组合共识，不使用目标价、评级变化或事后热门股标签。

本阶段只判断历史覆盖与共识样本是否足够，**不读取价格或未来收益**。

## 数据与点时边界

- 数据源：Tushare `broker_recommend`；字段仅为月度、券商、股票代码和当时简称；
- 官方说明名单通常在每月 1–3 日更新，但没有逐条发布日期或时分秒；
- 因此名单统一视为每月 3 日收盘后才可知，最早只能在 3 日之后的首个交易日
  开盘执行，禁止倒填到月初首个交易日；
- 按“月份 × 券商 × 股票”去重；同一券商重复记录只计一票；
- 固定采集区间 2020-07 至 2026-08，每月都必须落一个分区，包括空分区；
- 单月接口上限 1,000 行，任何返回达到上限都视为可能截断并失败；
- 元数据审计可以统计 2/3/4/5 家券商共识的样本数，但不得据收益选择阈值。

## 数据晋级门槛

全区间必须 74/74 分区完整、无重复键、无非法代码、月份与分区一致、每月小于
接口上限，并覆盖至少 60 个非空月份。只有在元数据审计后先冻结唯一共识阈值、
开发期、持有期和账户规则，才允许读取价格。

即使开发期通过，仍只允许打开预先隔离的独立验证与后续压力期；没有账户级
年化、回撤、费用、容量和前向证据之前，不增加 `0/5`。
