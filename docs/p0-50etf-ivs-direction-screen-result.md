# P0 50ETF 隐含波动率价差方向筛选：结果

运行日期：2026-09-01。冻结合同见
[方向筛选合同](p0-50etf-ivs-direction-screen-contract.md)。本结果只读取至
2024-12-31；2025 年以后验证数据保持封闭。

## 裁决

**IVS 方向家族终止，不进入期权放大器；严格达标计数仍为 `0/5`。**

月度方向信息得到独立复现，但周频信息不稳定，不能支撑下一步风险放大：

- 月度 2019–2024 递归样本外 `R²_OS=6.46%`，预测与实现收益相关 `+0.220`，
  递归系数 100% 为负；
- 周频 `R²_OS=0.35%`、相关仅 `+0.027`，递归系数只有 `83.93%` 为负；
- 周频在 2019–2021 的预测相关为 `-0.100`，到 2022–2024 才转为 `+0.033`，
  没有跨期一致性；
- 20 万现实 ETF 周频账户年化 `+7.59%`、累计 `+54.77%`、最大回撤
  `-26.91%`。它优于同期买入持有的 `+2.88%` 年化，但远低于 50%，也不能把
  月度论文显著性直接当作周频期权交易信号。

因此不建立看涨/看跌期权价差、不读取 2025–2026 续命，也不靠杠杆把弱预测放大成
表面高收益。

周频分位差为正，说明横截面排序方向并非完全失效；但递归预测在前半样本反向、系数

外部论文自身也只报告约 1 的夏普和 10%–14% 的确定性等价收益增量，而非 50% 年化。
