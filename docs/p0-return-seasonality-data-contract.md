# P0 同月收益季节性：历史预热数据合同

冻结日期：2026-08-31。冻结时尚未读取本项目的季节性策略收益，严格策略计数为
`0/5`。

## 目的与边界

现有全 A 日线从 2013-08-29 开始，不能在不缩短形成期的前提下，为开发账户构造
"过去 5 年相同日历月"信号。本阶段只补齐形成窗口所需的 2007-12 至 2013-08
月末价格和复权因子，不计算候选、账户或未来收益。首次开发试跑发现，原定截至
2012-12 会令现有日线起点前的 2013-01 至 2013-08 缺失，使 2014-2018 的完整
5 年窗口被错误淘汰；因此在读取独立验证期前修正数据边界，而不改变策略规则。

## 来源与不可变口径

- 来源固定为当前已配置的 Tushare `monthly` 与 `adj_factor` 接口；
- 按自然月查询完整横截面，保存接口原始证券代码、交易日、月 OHLC、成交量、成交额、
  涨跌幅和同日复权因子；
- 月线接口以市场月末标记证券当月 K 线；若证券月末停牌，复权因子允许使用不晚于
  市场月末的该证券最近一条同源记录，并保存实际因子日期与滞后天数；不得使用月末
  之后的因子或默认填 `1`；
- 股票代码规范化为 `.SH`、`.SZ` 或 `.BJ`，原始字段同时保留；
- 唯一键为 `(symbol, month_end)`；重复键、非法 OHLC、非正收盘价、未来因子或无法
  找到历史复权因子均使数据审计失败；
- 原子写入 `research/return_seasonality_warmup/monthly.parquet`，同时输出来源、查询月、
  行数、证券数、覆盖月份、缺失和重复统计及文件 SHA-256；
- 只允许读取至 2013-08-31。2013-09 起继续使用项目现有点时日线；重叠的 2013-08
  月收益优先使用完整月末预热记录，不能让现有日线的首个不完整月份覆盖它；2021 年
  以后独立验证和压力数据在开发期通过前保持封闭。

数据合格只说明 5 年形成窗口可重建，不代表季节性机制有效，也不增加严格策略计数。
