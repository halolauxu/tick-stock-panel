# P0 主板微盘 × 财务质量动量合同

冻结时间：2026-09-03。冻结时不得读取本研究候选组合收益。

## 经济机制

裸微盘补偿容量和流动性风险，但机械持有市值最小的20只会持续把资金放进基本面正在
恶化的公司。静态财务生存过滤已经证明“只剔除坏公司”不能降低系统性回撤；本研究
不再调整过滤阈值，而检验另一条机制：**在完整保留主板微盘最小市值十分位的前提
下，用已公告财务质量与中期价格动量共同排序，选择经营改善已经被价格确认的20只。**

## 点时输入

- 财务数据复用已通过审计的三表年报快照，只在三表全部公告后的下一交易日使用；
- 年报快照年龄不超过550天，不使用后续修订倒填；
- 价格动量为信号日复权收盘价相对同一证券60个交易观察前的收益；
- 只允许沪深主板，继续排除创业板、科创板、ST、退市风险和上市不足180天证券；
- 财务数据审计 SHA-256 固定为
  `0fc106a8688f7e8cf06a8ba5aaadd0f92414d4f3f473c5c1e1ccdaeede9d9ac5`。

## 唯一排序

每个周末信号日在原始主板微盘最小市值十分位内，对以下四项分别做横截面百分位
排名并等权相加：

1. 归母净利润 / 总资产，越高越好；
2. 经营活动现金流 / 总资产，越高越好；
3. 负债率的相反数，越高越好；
4. 60日价格动量，越高越好。

按复合分数从高到低选20只；同分时按原总市值小、代码升序。只要求总资产和归母
权益为正，不增加盈利、现金流、商誉、价格或波动阈值，不枚举因子权重、动量窗口、
持仓数或质量定义。

## 账户与顺序门

复用裸主板微盘的周频下一开盘、20只、100股整手、真实费用、历史印花税、双边5bp
滑点、T+1、涨跌停、停牌、1%成交额容量、退出重试、退市核销和资金账规则。

- 开发期：2014–2020；
- 独立验证：2021–2023；
- 已知压力期：2024–2026-08。

20万元开发主账户必须年化不低于45%、最大回撤不差于-35%、2014–2020七年全部
为正、买卖执行率均不低于80%、无未解决退出、资金账误差不超过0.01元，才允许
读取独立验证。

验证期必须年化至少35%、2021–2023三年全部为正、最大回撤不差于-25%，并通过
相同执行和账务门槛，才允许读取压力期。

压力期要求2024、2025、2026全部为正，且2026截至8月28日收益大于30%。三段全部
通过后才允许进入至少60个交易日的前向模拟；任一顺序门失败，冻结的财务质量动量
机制终止，不修改排序、权重、窗口或持仓数。
