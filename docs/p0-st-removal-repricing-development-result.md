# P0 撤销 ST 风险警示重定价开发结果

结论：**TERMINATE，不建统一账户、不读取验证集，严格计数仍为 `0/5`。**

245 个历史撤帽事件中 195 个可交易，覆盖 155 个独立信号日，可交易率 97.01%。但固定 20 日平均净收益为 -2.31%，相对同日全 A 股的平均超额为 -1.98%，超额聚类 t 值 -2.21；7 年中只有 2015 年平均超额为正，并有 2 笔未解决退出。

结果方向与“撤帽后继续重定价”相反，说明可交易的价格反应大多已在名称生效前发生，生效后追入没有正期望。不改变持有期、不把 2015 年单独抽出，也不研究反向做空，因为 A 股普通账户无法稳定实现该卖空。
