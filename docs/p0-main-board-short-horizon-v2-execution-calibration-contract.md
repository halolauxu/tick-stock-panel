## 3. 冻结计算

- 日线模拟成交价 = `gross / raw_shares`；

- 买入价格越高、卖出价格越低均记为不利偏差；同时报告绝对偏差的中位数、P95 和
  最大值，单位为基点；
- 容量分别按订单金额不超过竞价成交额 1%、09:31 分钟成交额 5% 检查；
