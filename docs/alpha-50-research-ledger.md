# 年化 50% 研究总账

更新时间：2026-08-31

## 当前裁决

严格达标策略数：**0 / 5**。

只有同时通过冻结规则、独立验证、后续压力期、20/30/50/100 万元真实账户、
费用与滑点、T+1、涨跌停、停牌、容量、资金账和至少 60 个交易日前向模拟的
经济机制，才允许增加计数。开发期超过 50%、局部年份暴利、事件平均收益、
工程跑通或数据可用都不算达标。

## 资金方案现状

20 万元是研究基准，30/50/100 万元是容量阶梯，不是已经分配的投资组合。
在 `0/5` 状态下，没有任何研究策略获得模拟投资预算；也不存在可以把多个失败
策略收益相加后宣称组合年化超过 50% 的合法口径。下一次计数变化必须来自一条
新的、完整通过独立验证与压力检验的机制，而不是参数变体。
