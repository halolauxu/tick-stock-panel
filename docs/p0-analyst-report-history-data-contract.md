# P0 分析师研报历史：数据合同

冻结日期：2026-08-31

## 目的与边界

本阶段只建立可追溯的历史研报元数据镜像，不计算任何股票收益，也不定义最终
交易候选。目标是判断“券商评级或目标价修订”是否具备足够的点时字段、历史
跨度和多券商样本，再在看收益前冻结机制合同。

## 来源与时钟

- 来源固定为东方财富官方研报列表接口 `reportapi.eastmoney.com/report/list`；
- 该接口 2013–2016 返回 0，完整开发元数据从 2017 年开始；不得把当前一致
  预期快照倒填成历史研报；
- `publishDate` 为唯一信号可见日；无时分时一律按收盘后可知处理；
- 保存报告 ID、股票、券商、发布日期、当前/前次评级、目标价上下界和报告类型；
  不保存也不计算入场、退出或未来收益；
- 每年完整分页并核对 `hits`、总页数和实际行数，报告 ID 去重后原子写入
  `event_data/analyst_reports/year=YYYY/part.parquet`。

数据审计只允许统计字段覆盖、历史报告间隔、券商宽度和潜在事件数量；任何价格
连接必须等独立机制合同冻结并提交后才能发生。
