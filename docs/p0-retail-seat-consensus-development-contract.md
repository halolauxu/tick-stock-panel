# P0-D2 龙虎榜营业部共识开发期合同

状态：冻结

冻结日期：2026-08-30

## 1. 经济机制

龙虎榜中的普通券商营业部代表与机构专用、沪深股通不同的交易群体。若多个互不相同的营业部在同一异常交易日形成广泛净买入，而且净买额相对当日成交额足够大，这可能是分散的事件知情交易或注意力扩散，而非单一席位噪声；价格未封涨停时，部分需求可能在披露后继续释放。

本研究只检验一个方向：**多营业部强净买入共识后的最早 T+1 延续**。它不复活已经失败的机构专用/北向专用席位规则，也不按营业部历史收益挑“明星游资”。

## 2. 数据去重与唯一信号

- 样本为 2014-01-01 至 2020-12-31 龙虎榜席位明细，只读取开发期收益；验证期 2021-2023 和压力期 2024-2026-08 暂不读取。
- 同一股票、交易日、席位重复出现在买方榜、卖方榜或多个上榜理由时，先按席位合并，只保留该席位一组最大买入额、卖出额、净买额和占比，不能重复计票。
- 排除名称含“机构专用”“沪股通专用”“深股通专用”的席位。
- 一个股票日同时满足以下条件才产生信号：
  - 净买入的不同普通营业部不少于 8 个；
  - 普通营业部合计净买额为正，且不低于该股当日成交额的 5%；
  - 净买入营业部买入占比合计不低于 10%；
  - 信号日非 ST/退市整理、上市满 180 天、成交额不少于 2,000 万元；
  - 信号日收盘未封涨停。
- 同一股票 20 个自然日内只保留第一次信号；不按上榜理由、当日涨幅、市值、板块或营业部名称再切分。

## 3. 成交与收益时钟

- 龙虎榜收盘后披露，信号后的下一交易日开盘买入；买入后的下一交易日开盘卖出，满足 A 股 T+1。
- 买入遇停牌、行情缺失或开盘涨停即拒绝；卖出遇跌停可最多顺延 20 个交易日，仍无法退出记为未解决，不倒填成交。
- 原始价格判断涨跌停和容量，点时复权价格计算收益。
- 单笔名义金额 2 万元，买卖金额均不得超过当日成交额 1%；往返计双边各 2bp 佣金、各 5bp 滑点和历史有效卖出印花税。
- 同期基准为同一入场日全体合格 A 股从开盘到下一交易日开盘的中位数收益。

## 4. 开发晋级门槛

必须同时满足：可成交事件至少 500 个、独立事件日至少 200 天、可交易率至少 90%、市场基准覆盖至少 99%、2 万元容量可行率至少 95%、未解决退出为 0；平均单笔净收益至少 1.00%、平均市场超额至少 0.75%、事件日聚类超额 t 值至少 2.5、至少 5 个自然年超额为正，且最盈利单一年不贡献超过全部正超额的 50%。

开发期失败即 `TERMINATE`，不得改成 5/6/10 个席位、调整净买占比、改持有期或选择历史盈利营业部。开发期通过也只允许冻结账户规则并进入独立验证，不计入年化 50%目标。
