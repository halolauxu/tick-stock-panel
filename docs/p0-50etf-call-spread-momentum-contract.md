# P0 50ETF 有界认购价差趋势合同

冻结日期：2026-08-31。运行前严格策略计数为 `0/5`。

## 经济机制

股票指数趋势延续在强市中可能覆盖期权时间价值损耗。为在20万元账户上获得非线性
上行暴露，同时把最坏损失锁定，本策略买入近平值认购并卖出相邻更高执行价认购。
收益来自ETF方向与凸性，不来自卖出ATM波动率；因此与已经失败的铁蝶保险溢价是
相反的风险暴露，不允许把两者收益合并或作为同一候选重复计数。

## 冻结规则

- 标的与数据：`510050.SH`及其上交所标准乘数10,000期权；开发期2015-02-09至
  2020-12-31；开发失败不收集或读取2021年后期权价格；
- 对每个月度到期日，在到期日前第21个ETF交易日收盘判断；ETF收盘必须高于此前
  60个交易日（不含当日）的收盘均线，且相对20个交易日前收盘涨幅不低于3%；
- 选择执行价最接近信号日ETF收盘价的标准认购为买腿，并卖出同到期日下一档更高
  执行价认购；不得按历史收益选择宽度；
- 两腿信号日前一交易日各自成交量至少100张、持仓量至少500张；
- 信号后下一ETF交易日开盘同时建仓，到期日前第5个ETF交易日开盘同时平仓；任一腿
  缺少有效开盘价则整组不成交，不用未来价格回填；
- 每腿每次开平佣金5元/张，完整价差共4个腿次；每次开平每腿施加一跳不利价格；
- 单组最大损失为建仓净支出加完整往返佣金；每月总最大损失不得超过交易前权益10%，
  同时至少保留50%现金；两腿数量相同且为整数张；
- 持仓逐日按两腿收盘价估值；无效时依次用当日结算价、此前已知价，只向前沿用。

## 闸门

20/30/50/100万元分别空仓启动。20万开发账户必须同时满足：净年化不低于50%、
最大回撤不差于-25%、至少20个完整价差、至少4/6年为正、建平仓完整率不低于90%、
资金误差不超过0.01元。任一失败即终止且不打开验证；通过开发也不能直接计入5个
策略。
