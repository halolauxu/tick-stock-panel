# Serenity 卡点策略：7 天、100 家公司前向小样本

## 结论边界

本试验只回答两个问题：

1. 公告原文与 OCR 数据在本项目中的真实存储、抽取成功率和候选事实密度是多少；
2. `serenity_bottleneck_research` 的点时选股、次日执行、基线对照和收益结算能否完整运行。

7 个自然日通常只有约 5 个交易日，不能证明策略存在稳定收益。即使短期收益为正，报告仍固定为
`UNVERIFIED_ALPHA`；至少累计 60 个交易日和 200 个已结算持仓后，才允许进入 Alpha 验证。

## 冻结样本

样本总数固定为 100 家，开始后不替换：

| 产业链 | 数量 | 角色 |
| --- | ---: | --- |
| 半导体前道设备与材料 | 34 | 候选链 |
| AI 算力互连与液冷 | 33 | 候选链 |
| 锂电材料 | 33 | 过剩型负对照链 |

样本来自试验开始前已落盘的同花顺概念快照、个股维表与日 K。每条链先按流通约束过滤，
再按市值分成小、中、大三层并做确定性抽样。选择逻辑不读取试验期收益，防止事后挑股。
概念归属只用于构造待验证样本，不被当作“卡点成立”的证据。

## 数据来源和存放

- 公告目录和 PDF：巨潮资讯官方公开披露平台；Tushare `anns_d` 实测无权限，不使用该接口；
- 产品级主营构成：现有 Tushare `fina_mainbz` 权限，首次运行按 100 家公司冻结一次；
- 行情、财务、指数：项目已落盘的点时日 K、财务指标和沪深 300 指数；
- 试验库：`data/research/serenity_pilot/<pilot-id>/pilot.duckdb`；
- 原始 PDF：同目录 `documents/`；抽取文本：同目录 `text/`。

主数据集不会被改写。试验库包含 `universe`、`announcements`、`document_metrics`、
`evidence_facts`、`main_business`、`decisions`、`outcomes` 和 `collection_runs`。

## 存储和请求硬上限

- 7 个自然日；
- 100 家公司；
- 最多 600 份 PDF；
- 原始 PDF 合计最多 2 GB；
- 单份 PDF 最多 50 MB；
- 每家公司最多 6 份；
- 低文本 PDF 每份最多 OCR 8 页；
- OCR 页图只在内存中生成，测量后立即释放，不落盘；
- 巨潮查询串行执行，间隔不低于 450 ms；Tushare 使用现有统一限流客户端。

达到任一上限后，后续文件记录为 `capped`。报告必须显示样本被截断，不能把截断样本描述为全量。

## 三项数据测量

### PDF 均值

报告原始 PDF 的样本数、均值、中位数和 P95，同时报告实际原始字节总量。仅报告均值会被大年报
扭曲，因此扩大采集时使用 P95 和总量共同估算。

### OCR 膨胀率

分开记录两种口径：

- 持久化文本膨胀率：`抽取文本字节 / 原始 PDF 字节`；
- OCR 临时渲染倍数：`被 OCR 页的 PNG 字节 / 原始 PDF 字节`。

PNG 不落盘，第二项只用于估算峰值内存和临时空间。只有低文本页会进入 OCR；未 OCR 的原生文本
PDF 不参与 OCR 临时倍数均值。

### 事实密度

事实密度是带页码、类别和原句的规则命中候选数，按“每份 PDF”和“每 100 页”报告。候选类别为：

- 订单/需求；
- 产能/爬坡；
- 供应商集中与国产替代；
- 客户认证；
- 产品经济性；
- 投资与扩产项目。

规则命中不等于事实成立。扩大采集前必须人工复核至少 50 条，精确率达到 80%；否则事实层状态
保持 `UNVALIDATED_RULE_CANDIDATES`，不得进入卡点评分。

## 策略和收益口径

每天收盘后，只使用当日收盘前已经可得的数据冻结四组选择：

- `serenity`：现有 36 分自动初筛，最多 10 家；
- `momentum`：同一 100 家样本中的 60 日动量前 10；
- `random`：按日期与股票代码确定性抽取 10 家；
- `chain_equal`：100 家等权基线。

当前 64 分供应链证据仍然是未知；未经人工复核的 PDF 候选事实不会自动加分。

所有组合在下一个交易日开盘价进入，分别以第 1、3、5、10、20 个持有交易日收盘价结算，
研究成本固定扣 20 bp，同时记录沪深 300 超额、同链等权超额、MAE 和 MFE。未到期结算保持
`pending`。不存在同日收盘信号按同一收盘成交的写法。

## 7 天验收

数据工程通过需同时满足：

- 公告元数据到 PDF 的覆盖率不低于 80%；
- PDF 解析成功率不低于 95%；
- 每份文件都有 SHA-256、页数、原始字节和抽取字节；
- 未突破 2 GB 原始 PDF 上限；
- 人工复核 50 条候选事实后精确率不低于 80%。

收益结果只做方向性判断：至少有 20 个 3 日持仓结算后，才显示均值、分布和相对三组基线结果。
不足 20 个显示 `INSUFFICIENT_OBSERVATION`。无论正负，7 天都不能升级为“已证明收益”。

## 运行

容器内初始化：

```bash
uv run python -m app.services.serenity_pilot init --start-date 2026-08-27
```

每日盘后运行：

```bash
uv run python -m app.services.serenity_pilot run-daily \
  --start-date 2026-08-27 --as-of 2026-08-27
```

查看汇总：

```bash
uv run python -m app.services.serenity_pilot status --start-date 2026-08-27
```

### 立即回补最近 7 个已收盘交易日

这条命令按本地日 K 分区识别真实交易日，不用自然日倒推；结果写入独立目录，不会与前向样本混用：

```bash
uv run python -m app.services.serenity_pilot run-historical \
  --end-date 2026-08-26 \
  --trading-days 7
```

历史回补属于 `RETROSPECTIVE_ENGINEERING_SAMPLE_NOT_CLEAN_ROOM`。价格与财务字段按决策日读取，
次一交易日开盘入场并扣除 20bp 研究成本；但概念成分和个股维表只有当前快照，报告会将这两项
标成 `UNRESOLVED_CURRENT_SNAPSHOT`。PDF/OCR 事实只用于测量数据经济性，未经人工复核不会进入
策略评分。因此该结果可以回答“流程是否跑通、样本收益是否为正”，不能证明稳定 Alpha。
