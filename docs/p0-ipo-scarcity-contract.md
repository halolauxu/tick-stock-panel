# P0-H1 次新股筹码稀缺动量研究合同

状态：冻结（只允许读取开发期收益）

冻结日期：2026-08-30

经济机制：新股上市初期可流通筹码比例低、卖方覆盖不足、投资者注意力集中，价格发现可能在开板后数月继续进行。只有已经脱离最初无量涨停阶段、具有真实成交并形成中期趋势的次新股才进入候选。该收益来源是新发行筹码稀缺与信息扩散，不等同于全市场普通动量或微盘排序。

## 1. 样本与时钟

- 开发期：2014-01-01 至 2020-12-31；本阶段不得读取 2021 年及以后收益；
- 使用点时上市日期、历史名称、已公告总股本和流通股本；
- 每周最后一个交易日收盘后产生信号，下一交易日开盘先卖后买；
- 初始资金20万元，最多10只等权，100股整手，执行A股T+1、费用、涨跌停、停牌和容量约束。

## 2. 固定信号

- 上市满60天但不超过365个自然日，当时非ST/退市整理；
- 点时流通股本/总股本不高于50%；
- 20个相邻交易观察的复权收益位于 +10% 至 +50%，收盘高于20日均线；
- 最近20日平均成交额不少于1亿元，信号日未复权收盘价3–300元；
- 信号日复权涨幅不高于5%，避免把已经封板或单日加速后的不可实现跳空当作入场依据；
- 按20日收益从高到低、流通比例从低到高、成交额从高到低、代码稳定排序，持有前10只。

不得在看结果后修改上市年龄、50%流通比例、20日、10%–50%动量、1亿元、5%信号日涨幅、周频或持仓数。

## 3. 执行与成本

- 次日开盘停牌、封死涨停、行情缺失、整手为零或订单超过当日成交额1%时拒绝买入；
- 已持仓停牌或封死跌停时继续持有并记录原因；
- 双边佣金各2 bps且最低5元，双边滑点各5 bps；卖出印花税按历史日期取10 bps或5 bps；
- 账户逐日按当时可靠收盘估值，禁止未来回填。

## 4. 开发期晋级门槛

必须同时满足：

- 20万元账户年化净收益不低于50%；
- 相对同期全A股点时等权日收益基准的年化超额不低于20个百分点；
- 最大回撤不低于-30%，2014–2020至少5个自然年收益为正；
- 平均现金比例不高于25%，买入和卖出执行率均不低于90%；
- 期末无无法估值持仓，现金最大对账误差不超过0.01元。

开发期晋级仍需冻结后的独立验证、压力期、四档容量和前向模拟；本阶段不增加严格达标计数。
