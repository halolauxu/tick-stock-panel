# P0 主板微盘 × 股权质押风险合同

冻结时间：2026-09-03。冻结时不得读取本研究候选组合收益。

## 经济机制

高比例股权质押会把股价下跌转化为补充担保、被动减持和流动性冲击。该机制不把
“低质押”当作普通质量因子，而是用实际公告的重大新增质押识别两种风险：单只股票
未来一段时间的强平脆弱性，以及全市场重大质押公告集中出现时的系统性压力。

## 点时数据门

- 只使用 Tushare `pledge_detail` 逐笔公告，不使用缺少公告时间的 `pledge_stat`
  周度历史统计；
- 事件在 `ann_date` 后的下一交易日才可使用；
- `p_total_ratio` 缺失时，只允许用同一行的
  `pledge_amount / holding_amount * h_total_ratio` 推导；
- `is_release=1` 的记录只作为解押记录，不制造新增风险；
- 先完成2014年至2026年8月的无价格覆盖审计。每个完整开发年度至少50个主板重大
  新增质押事件，质押比例直接或可推导覆盖率至少95%，不得读取价格、收益或微盘
  候选表现。

## 冻结信号

重大新增质押定义为：非解押公告且本次质押占总股本比例不低于5%。同时冻结三个
研究臂，结果后不得增加第四个候选：

1. **个股禁入**：公告后的下一交易日起126个交易日内，从裸主板微盘池剔除该股；
2. **系统开关**：每个周频调仓日统计过去20个交易日内发生重大新增质押的主板公司
   数。至少积累52个历史周后，若当前数量不低于此前52周的90%分位且不少于10只，
   当周微盘风险仓位清零；
3. **组合臂（主候选）**：同时执行个股禁入与系统开关。

所有分位数只使用当时以前的数据。解押不提前缩短126日禁入窗，避免用不完整的质押
关系重建做乐观假设。

## 账户口径与顺序门

复用主板微盘的下一交易日开盘、20只、100股整手、真实费用、历史印花税、双边5bp
滑点、T+1、涨跌停、停牌、1%成交额容量、退市核销、退出重试和资金账规则。

- 开发期：2014–2020；
- 独立验证：2021–2023；
- 已知压力期：2024–2026-08。

开发期主候选必须年化不低于35%、最大回撤不差于-30%、2014–2020七年全部为正、
买卖执行率均不低于80%、无未解决退出且资金账误差不超过0.01元，才允许读取独立
验证。两个诊断臂只解释机制，不得越过失败的主候选晋级。

独立验证必须年化至少30%、2021–2023三年全部为正、最大回撤不差于-25%，并通过
相同执行和账务门槛，才允许读取压力期。

压力期最终要求2024、2025和2026全部为正，且2026截至8月28日收益大于30%。三段
全部通过后才允许进入前向模拟；任一顺序门失败，整个冻结质押风险机制终止，不修改
5%、126日、20日、52周、90%分位或10只阈值。
