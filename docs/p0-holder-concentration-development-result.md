# P0 股东户数收缩：开发期结果

结论：**终止单独机制，不计入年化 50%策略目标。**

- 2014–2020 共读取 172,191 条有效点时披露，15%收缩、20–180 日比较窗口和 60 日冷却后得到 6,979 个事件；
- 4,657 个事件可交易，覆盖 888 个公告日；可交易率 98.12%，基准覆盖率与 2 万元容量可行率均为 100%；
- 20 日平均净收益 +1.648%，平均超额 +1.879%，超额日聚类 t 值 5.99；7/7 年平均超额为正，单年最大正贡献占比 27.46%；
- 绝对净收益低于冻结的 3%门槛，超额低于 2%门槛，并有 64 个已入场但 20 日顺延后仍无法退出的事件；
- 2017–2019 三个年度平均绝对收益为负，说明稳定相对 Alpha 仍不足以独立承担高收益目标。

该结果保留“筹码集中是有效相对筛选信息”的证据，但单独事件策略终止，不修改收缩比例、持有期或退出规则。
