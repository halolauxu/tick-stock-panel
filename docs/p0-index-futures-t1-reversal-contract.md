# P0 股指期货承接 T+1 延迟卖压反转合同

冻结日期：2026-08-31。研究运行前严格计数为 `0/5`。

## 经济机制

A 股当日买入的股票不能当日卖出。放量下跌日中形成的追随性卖压会有一部分延迟到
下一交易日，而已有研究发现此后的反转主要落在下一交易日盘中，而不是隔夜。
直接在下一日开盘买股票无法在收盘卖出，因此本研究使用可日内平仓的中国股指期货
承接该反转。这是结算制度与交易工具错配产生的机制，不是个股横截面反转的参数变体。

参考的冻结方向来自论文 *Positive feedback trading, the T+1 rule, and asymmetric
return reversals in China*（Economic Modelling, 2026，DOI:
`10.1016/j.econmod.2026.107783`）。论文只提供机制和方向，不提供本账户的收益保证。

## 冻结标的与时钟

| 期货 | 信号指数 | 乘数 |
|---|---|---:|
| IF 主力连续 | 沪深 300（000300.SH） | 300 元/点 |
| IH 主力连续 | 上证 50（000016.SH） | 300 元/点 |
| IC 主力连续 | 中证 500（000905.SH） | 200 元/点 |

- 开发：2015-01-01 至 2020-12-31；
- 独立验证：2021-01-01 至 2023-12-31，开发通过前不得计算；
- 压力：2024-01-01 至 2026-08-28，验证通过前不得计算；
- 每个信号日收盘后，只用当日及过去数据决策；
- 下一交易日以主力合约开盘价买入，收盘价平仓，不持有隔夜仓位。

## 唯一开发规则

对每个指数计算当日收盘收益和前 60 个交易日成交额分布。候选必须同时满足：

1. 当日指数收益小于 0；
2. 当日成交额高于截至前一日的 60 日第 75 百分位；
3. 过去 60 日数据完整。

若同日多个指数满足，按 `-当日收益 × 当日成交额 / 前60日成交额中位数` 取最高
一个，不同时持有高度相关的多个指数合约。不得在看到结果后修改 60 日、75 分位、
方向、选择分数或新增指数。

## 账户与成本

- 账户分别从 20/30/50/100 万元空仓启动；
- 保证金按合约名义价值 15%冻结，至少保留 15%现金缓冲；
- 合约数为保证金、现金缓冲和当日成交量共同允许的最大整数，名义敞口不超过权益
  5.5 倍，订单不超过合约当日成交量的 0.1%；
- 每次完整开平按名义价值扣 5bp，统一覆盖手续费、平今成本和两端滑点；
- 开盘或收盘无有效价、成交量为零、高低价相同均拒绝成交；
- 日终权益、保证金、费用、成交和拒单必须守恒。

开发期主账户必须同时达到：净年化不低于 50%、最大回撤不高于 25%、至少 60 笔
完整日内交易、正收益年份不低于 4/6、20 万账户成交率不低于 90%。任一失败立即
终止，不读取独立验证收益。开发通过后，独立验证与压力期仍分别要求年化不低于
50%、最大回撤不高于 25%，且四档资金均通过容量与账务门。
