# VWAP 乖离因子复权口径修复

发现日期：2026-09-03

## 问题

日线存储中的 `close` 是前复权价格，而 `amount / (volume * 100)` 得到的是未复权
成交均价。旧公式用两种不同价格尺度相除，历史除权因子会被错误解释为 VWAP 乖离，
并可能在截面排序和 Alpha 自动研究中产生伪信号。

## 修复

- `vwap_bias` 改为 `raw_close / (amount / (volume * 100)) - 1`；
- 将 `raw_close` 加入该虚拟因子的必需依赖，缺失时 fail closed；
- 单元测试显式设置复权价与未复权价不同，防止回归；
- 受影响的短周期全因子上限筛查必须重跑，旧结果不得用于策略判断。

其他使用完全复权 OHLC 比值的技术因子不受此问题影响。
