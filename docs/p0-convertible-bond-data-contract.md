# P0 可转债研究数据合同

冻结日期：2026-08-30

## 目标

为可转债价格、转股价值与溢价机制建立包含退市债券的开发期数据镜像。数据合格不代表策略有效，也不增加严格策略计数。

## 数据源与范围

- 主表：Tushare `cb_basic`，保留沪深代码、上市日不晚于 2020-12-31、且未在 2017-01-01 前退市的可转债。
- 日线：Tushare `cb_daily`，范围 2017-01-01 至 2020-12-31，逐只提取 OHLCV、成交额、纯债价值、转股价值和转股溢价。
- 成交额原单位万元，统一乘 10,000 换算为元；原始成交量保留。
- 主表纳入后来退市的债券，不允许用今天仍存续的转债列表回看历史。

## 合格门槛

- 主表代码唯一，上市/退市日期关系合法；
- 日线证券日键唯一，且只出现在上市日至退市日之间；
- 日线覆盖至少 95% 的冻结主表证券；
- 有成交的行 OHLC 均为正，成交量和换算后成交额非负；
- 有成交行的转股价值与转股溢价覆盖至少 95%；
- 任一接口请求失败整轮失败，不发布半成品；
- 原子写入独立 `research/convertible_bond/`，不覆盖应用数据。

只有审计为 `DATA_QUALIFIED`，才允许在不读 2021 年以后收益的前提下冻结可转债策略合同。
