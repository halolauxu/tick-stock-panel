# P0 可转债强赎条件逼近：开发期结果

运行日期：2026-08-31  
冻结合同：`p0-cb-call-condition-approach-development-contract.md`  
结果摘要 SHA-256：`8949a38f0d089e39085186299659c234d12374979c2d9bb3b8d90230618b2845`

## 结论

开发期失败，终止该方向，不读取独立验证期，也不计入年化 50% 目标。

## 样本与执行

- 2017–2020 年普通公募可转债 426 只；
- 197 个冻结事件、165 只正股、147 个信号日；
- 194 个事件符合股票池，193 个可成交，可交易率 99.48%；
- 基准覆盖率 100%，开仓容量可行率 100%，未解决退出 0；
- 193 个成交事件中，130 个在入场后第 5 个交易日达到 15/30 条件，26 个到
  第 20 个交易日仍未达到而按冻结上限退出。

## 收益证据

| 年份 | 平均净收益/笔 | 平均市场超额/笔 |
|---|---:|---:|
| 2017 | -3.62% | -3.26% |
| 2018 | -11.59% | -9.12% |
| 2019 | -2.03% | -1.36% |
| 2020 | +0.04% | +1.41% |
| **全部** | **-0.68%** | **+0.53%** |

信号日聚类市场超额 t 值仅 0.36；四年只有一年平均超额为正，全部正超额贡献
来自 2020 年。绝对收益、市场超额、显著性、跨年稳定性和集中度门槛全部失败。

## 研究判断

“接近强赎条件时发行人可能推动正股”的经济叙事没有转化为可交易的开发期收益。
它不能作为独立策略，更不能因为 2020 年为正就调整 10/15/30 日阈值继续拟合。
