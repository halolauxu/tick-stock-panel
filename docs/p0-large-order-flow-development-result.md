## 4. 研究裁决

1. 不修改 10% 大单净流量占比、1,000 万元、5 日持有期或事件日涨跌区间；
2. 不用 7 个正超额年份和显著 t 值掩盖绝对收益不足；
3. 不删除未解决退出，也不把大样本下的微弱显著性包装成高收益；
4. 不打开 2021–2023 验证期。
