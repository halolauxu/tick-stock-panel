# P0-E 市场微观结构数据审计合同

状态：冻结

冻结日期：2026-08-30

目标：在低频公告机制之后，审计三类能够支撑高周转策略的点时数据。数据可取只表示可以研究，不代表收益有效，也不计入年化 50% 策略数量。

## 1. 预注册数据源与机制

| 数据源 | 最早信号时钟 | 待验证机制 |
| --- | --- | --- |
| `moneyflow` 个股大中小单资金流 | 当日收盘后 | 大单净流入的延续，或极端单边流出后的流动性反转 |
| `margin_detail` 融资融券明细 | 当日收盘后 | 杠杆资金突然扩张后的注意力延续，及拥挤去杠杆风险 |
| `stk_auction_o` 开盘集合竞价 | 09:25 竞价结束后 | 竞价量价失衡在 09:30 后的延续或反转；只允许使用带可靠交易日的历史快照 |

三者是独立数据机制，不能用不同阈值把同一资金流重复计数。日终数据一律下一交易日开盘执行；集合竞价若进入研究，必须另行冻结 09:25 数据可得性、09:30 成交证据和一分钟级撮合口径。

## 2. 跨期抽样

- `moneyflow` 与 `margin_detail`：分别抽取 2019-01-31、2024-01-31、2026-01-30；
- `stk_auction_o`：抽取 2024-09-30、2025-08-29、2026-08-28，防止用接口上线前空值误判为权限失败；
- 每个样本输出行数、唯一股票数、日期范围、重复键、关键字段缺失率和接口上限命中；
- 权限错误、接口成功但空数据、关键字段污染必须分开记录。

## 3. 进入研究的最低门槛

- 至少两个相隔时期非空，且所有抽样请求成功；
- 股票代码、交易日和机制核心字段缺失率不高于 1%；
- 能与本地全 A 点时证券主数据和日线按 `symbol + trade_date` 连接；
- 数据单位和接口行数上限可通过小样本核验；
- 集合竞价若没有覆盖独立历史验证期，只能作为前向研究，不得以短历史年化计入目标。

通过审计后，先冻结经济方向、事件阈值、持有期与杀死标准，再做开发期；不得在验证期上搜索。
