## 1. 结论

**六类事件数据均可进入有界采集；优先级第一为业绩预告。**

业绩预告同时具备明确公告日、跨期大样本、方向与幅度字段，并能直接检验公告后漂移。回购、股东增减持、龙虎榜和大宗交易也通过；限售解禁有极少量关键字段缺失且季度请求命中 6,000 行上限，需要更细分区和失败闭合。

接口可取只代表数据基础具备，不代表任何事件策略能够达到 50%。当前严格达标计数仍为 **0 / 5**。

## 3. 采集顺序

1. 业绩预告：按公告日采集，保存首次公告日、报告期、预告类型、利润变动上下限和净利润上下限；
2. 股票回购：按月采集并区分方案、股东大会通过、实施和完成，避免重复把同一计划当成多次新信号；
3. 股东增减持：按月采集并按公告日、股票、方向聚合，保留股东类型和占流通股比例；
4. 龙虎榜与大宗交易：按交易日采集，与次日开盘及后续收益连接；
5. 限售解禁：按较短解禁日期窗口采集，先按股票与解禁日汇总解禁比例，再检查公告日是否早于信号日。

所有正式事件信号最早在事件日收盘后形成，下一交易日开盘成交；公告只有日期没有时分秒时，一律保守按盘后处理。
