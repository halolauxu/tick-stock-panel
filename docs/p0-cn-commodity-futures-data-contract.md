# P0 中国商品期货趋势研究数据合同

冻结日期：2026-08-30

## 目标与边界

为中国商品期货跨品种趋势建立主力映射、合约乘数和日线数据镜像。这是对 A 股系统之外、但属于境内小资金可交易资产的独立收益源探索；数据合格不代表策略有效，也不增加严格策略计数。

## 冻结品种

- 上期所：`CU.SHF`、`AL.SHF`、`ZN.SHF`、`AU.SHF`、`AG.SHF`、`RB.SHF`、`HC.SHF`；
- 大商所：`M.DCE`、`Y.DCE`、`P.DCE`、`C.DCE`、`I.DCE`、`J.DCE`、`JM.DCE`；
- 郑商所：`CF.ZCE`、`SR.ZCE`、`TA.ZCE`、`MA.ZCE`、`RM.ZCE`、`OI.ZCE`。

不在看到收益后增删品种。开发数据为 2014-01-01 至 2020-12-31，不读取 2021 年后收益。

## 数据源与合格门槛

- Tushare `fut_daily` 获取各主力连续序列 OHLC、结算、成交量、成交额与持仓量；
- `fut_mapping` 获取每个交易日对应真实主力合约；
- `fut_basic` 获取真实合约上市/退市日和每手数量 `per_unit`；
- 主力日线和映射的证券日键分别唯一，活跃行情 OHLC/结算为正、成交量与持仓非负；
- 每个冻结品种至少 1,500 根日线；日线与主力映射日期交集覆盖至少 99%；
- 所有被映射真实合约都必须存在于主表，且 `per_unit` 为正；
- 任一请求失败整轮失败；产物原子写入独立 `research/cn_commodity_futures/`。

连续合约跨换月的价格跳变不得直接计入收益。只有审计为 `DATA_QUALIFIED`，才允许在不知道开发收益的前提下冻结趋势、保证金、换月和整数合约规则。
