## 1. 裁决

**TERMINATE：过去 20 个观察的大单净流入没有增强微盘溢价，反而把开发期年化从同账户对照的 51.59%降到 10.15%。不读取验证期，不计入年化 50% 策略。**

## 4. 对照结果不能计入目标

对照组合在开发期年化超过 50%，但它不是合格策略证据：

1. 这是规则形成和研究使用的开发期，不是独立验证；
2. 最大回撤达到 -51.33%，明显超过验收上限；
3. 卖出执行率只有 57.59%，存在大量容量、缺行情和跌停拒绝；
4. 已有同机制 20 只微盘独立账户在验证期年化 34.71%、压力期年化 20.29%，证明不能外推开发期暴利；
5. 不允许在看到本结果后把“10只最小市值”另立为新策略并打开验证。
