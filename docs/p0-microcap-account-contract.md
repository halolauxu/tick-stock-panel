# P0-B2 微盘 30 万元统一资金账户研究合同

状态：冻结候选合同

冻结日期：2026-08-30

前置证据：P0-B 全 A 股横截面基线通过；见 `docs/p0-return-location-and-microcap-result.md`。

边界：本阶段只验证最小市值因子能否落入一个真实共享现金账户。不创建线上模拟账户，不使用灾难逃生规则，不宣称年化 50% 已实现。

## 1. 唯一候选

- 初始资金：人民币 `300,000` 元；不融资、不做空、不追加资金。
- 持仓目标：20 只；沪深主板、创业板和科创板使用 P0-B 相同的点时上市、退市、历史名称和股本口径。
- 股票过滤：排除 `ST`、`*ST`、名称含“退”、上市不足 180 个自然日、股本或收盘数据不可用的股票。
- 排序信号：每周最后一个完整交易日收盘后，按 `原始收盘价 × 当时已公告总股本` 从小到大排序。
- 候选队列：最小市值十分位内按市值从小到大排列。20 只是账户目标，不把“恰好第 20 名”当作可调参数。
- 调仓时间：信号后的下一交易日开盘；不在信号日收盘倒填成交。
- 持有方式：已持有且仍在本周目标前 20 的股票继续持有，不为了机械等权而重复交易。

本阶段不增加财务质量、动量、行业、价格或波动过滤。若裸微盘账户失败，不能通过逐项添加过滤条件把同一压力期调到通过。

## 2. 开盘执行顺序

每个调仓开盘严格执行：

1. 使用当日开盘价对昨日持仓做调仓前估值；无当日行情时沿用最后可见估值并标记 stale。
2. 对不在目标前 20 的持仓先发卖单。停牌、开盘跌停、成交额不足或行情缺失时不得卖出，持仓滞留并继续占用资金。
3. 成功卖出后释放现金；费用当笔入账。
4. 滞留仓和仍在目标内的持仓先占用持仓槽。剩余槽位从候选队列顺序补足。
5. 新标的停牌、开盘涨停、行情缺失或前一完整日/当日成交额容量不足时跳过，并保留固定拒绝原因；继续检查下一名候选。
6. 当次已经卖出的标的不得在同一开盘重新买回。
7. 没有足够可执行候选或现金时保留现金，不假设成交。

若滞留卖单导致实际持仓超过 20 只，不强制制造卖出；超限状态和持续周数必须进入结果。

## 3. 资金、股数和费用

- 每个新持仓的目标金额=`调仓前账户权益 / 20`。
- 买入数量按原始开盘价和 100 股整数手向下取整；数量为 0 时记录零手拒绝。
- 单笔买入和卖出金额均不得超过该股票当日成交额的 `1%`；同时沿用 P0-B 对信号日成交额的容量检查。
- 滑点：买卖各 5bp；买入提高成交成本，卖出降低成交收入。
- 佣金：买卖各 2bp，每笔最低 5 元。
- 卖出印花税：2023-08-28 前 10bp，此后 5bp。
- 所有费用从共享现金实时扣除；不得逐股票独立复利后再相加。

原始价格用于下单股数、涨跌停、成交额和现金流水。复权价格只用于在分红送转后保持持仓收益连续：买入时把原始股数换算为等值复权单位，卖出和每日估值按复权单位计价。该处理不得改变买入时的 100 股整数手和实际现金支出。

## 4. 估值与异常

- 每个交易日收盘按最后可见复权收盘价估值，形成日级权益曲线和回撤。
- 停牌期间沿用最后可见价格，但必须报告 stale 持仓、最长 stale 天数和期末 unresolved 持仓。
- 证券恢复交易后重新使用真实价格；不得用未来复牌价回填停牌期间。
- 研究结束仍无可靠估值或无法退出的持仓使账户不能通过完整性门槛。
- 每次调仓必须满足：期末现金 + 持仓市值 = 账户权益；累计现金流水与成交费用可重建该等式。

## 5. 时间角色和比较基准

- 开发期：2013-08-29 至 2020-12-31；只用于解释账户行为。
- 验证期：2021-01-01 至 2023-12-31。
- 已知压力期：2024-01-01 至 2026-08-28。
- 真正前向：合同冻结后的交易日。
- 比较基准：P0-B 同期全市场周频等权净收益；不得改用更弱的指数来提高超额。

## 6. 进入灾难逃生研究的门槛

P0-B2 只有同时满足以下条件，才允许冻结一条独立的灾难逃生合同：

- 验证期和已知压力期账户复合年化均不低于 `15%`；
- 两个时期相对全市场的年化超额均不低于 `10` 个百分点；
- 两个时期分别至少有 2 个绝对正收益年份；
- 买单和卖单的可执行率分别不低于 `80%`；
- 期末没有 unresolved 持仓，资金恒等式误差不超过 `0.01` 元；
- 输出日级最大回撤、最差周、换手、现金占比、持仓超限和拒绝原因，不删除 2024 年初灾难。

裸账户最大回撤不设通过线，因为本层目的之一就是测量未规避灾难的真实损失。若收益门槛通过但最大回撤超过 `25%`，只能进入单独冻结的逃生研究，不能进入模拟盘。逃生层最终必须把验证期和压力期最大回撤压到 `25%`以内，同时保留不低于 `15%` 的年化收益，否则微盘引擎降级为小仓位补充。
