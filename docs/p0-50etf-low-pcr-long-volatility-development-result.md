# P0 50ETF 极端低 PCR 次日做多波动率：开发期结果

运行日期：2026-08-31。冻结合同见
[开发期合同](p0-50etf-low-pcr-long-volatility-contract.md)。本结果只读取
2015-02-09 至 2020-12-31 开发期，2021 年以后独立验证和压力期均未读取。

## 裁决

**整个极端 PCR 做多波动率家族终止，严格达标计数仍为 `0/5`。**

低 PCR 后次日买入近平值认购和认沽跨式，在 20 万元账户中年化净收益
`-0.95%`、累计收益 `-5.46%`、最大回撤 `-10.57%`。它比极端高 PCR 对照少亏，
但年化优势只有 `+1.39` 个百分点；同期 50ETF 买入持有年化 `+7.83%`，候选落后
`8.78` 个百分点。开发闸门已经失败，因此不调整阈值、窗口、到期月、持有期或风险
比例，也不打开验证期续命。

## 冻结闸门

| 闸门 | 要求 | 结果 | 通过 |
|---|---:|---:|:---:|
| 20 万年化净收益 | ≥50% | -0.95% | 否 |
| 相对 50ETF 年化优势 | ≥20pp | -8.78pp | 否 |
| 相对高 PCR 对照优势 | ≥10pp | +1.39pp | 否 |
| 最大回撤 | ≥-25% | -10.57% | 是 |
| 正收益年份 | ≥4 / 6 | 2 / 6 | 否 |
| 完整跨式 | ≥30 | 62 | 是 |
| 信号执行率 | ≥90% | 92.54% | 是 |
| 最大正利润集中度 | ≤25% | 27.55% | 否 |
| 资金误差 | ≤0.01 元 | 约 0 元 | 是 |

这条路线验证了一个重要边界：**公开研究里的“可预测次日方差”不能直接等价为
“买入跨式可盈利”。** 期权买方还必须战胜隐含波动率定价、跳价和四个腿次的交易
摩擦；本开发样本没有做到。
