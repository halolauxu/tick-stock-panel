# P0 北向资金周度持股数据合同

冻结日期：2026-08-30

- 数据源：Tushare `hk_hold`，原始来源为港交所持股披露；只保留 `exchange=SH/SZ` 的北向持股，不混入港股通南向持股。
- 区间：2017-03-17 至 2024-08-16。交易所自 2024-08-20 起停止日度披露，因此不向后拼接季度数据。
- 频率：每个自然周最后一个 A 股交易日快照；交易日只从本地日线分区日期生成。
- 字段：股票代码、披露交易日、持股数量、占已发行股份比例、通道类型；保留原始名称用于审计。
- 本阶段只审计数据，不读取信号后的股票收益。

合格门槛：周度日期覆盖不低于 98%，唯一键无重复，北向股票代码有效，持股数量与比例非负，关键字段无缺失，每周至少 100 只北向持股。任一失败即停止策略研究。
