## 冻结规则与漏斗

- 股票范围仅沪深主板；先进入每个交易日流通市值后 10% 的微盘池；
- 财务数据只在公告后可用，且距信号日不超过 550 天；
- 对归母净利润 / 总资产、经营现金流 / 总资产、低负债率和 60 日动量做日内横截面
  等权排名；
- 每周选择复合分最高的 20 只，数量相同时仍按原始市值和证券代码确定顺序；
- 数据审计沿用已冻结财务审计，SHA-256 为

## 为什么停止这一家族

财务生存过滤、股权质押风险和本次质量动量复合都已经在同一主板微盘账户上完成冻结
检验；三者没有任何一条同时改善亏损年份、回撤和可执行性。继续改变财务权重、动量
窗口或选股数量会变成对开发期调参，因此财务质量叠加家族整体停止，后续转向独立的
市场级供给与流动性风险机制。
