# P0 主板微盘 × 财务生存质量合同

冻结时间：2026-09-03。冻结时不得读取本研究候选组合收益。

## 经济机制

微盘溢价来自壳价值、流动性补偿与散户偏好，但最大损失往往集中在持续亏损、经营
现金流枯竭、高杠杆或商誉占比过高的公司。财务生存过滤不预测短期涨幅，只试图从
原始主板微盘池中剔除最可能发生退市、债务和减值冲击的证券，在保留小市值溢价的
同时降低尾部损失。

## 点时数据

- 数据只来自本地 `income`、`cash_flow` 与 `balance_sheet` 年报；
- 每个字段使用该报表实际 `announce_date`，三张报表全部公开后的次一交易日才可用；
- 同一证券、同一报告期有多次版本时只保留最早公开版本，不使用后续修订倒填历史；
- 只使用 12 月 31 日报告期，财务快照年龄不得超过 550 天；
- 先完成不读取价格的覆盖审计。2013–2025 每个完整报告年度至少有 1,000 只主板
  证券具备三表合并快照，关键字段缺失率不得超过 5%。

## 冻结过滤

在原始主板微盘周频池（全主板市值最小十分位）中，仅保留同时满足：

1. 总资产与归母权益均为正；
2. 归母净利润为正；
3. 经营活动现金流净额为正；
4. 总负债 / 总资产不高于 70%；
5. 商誉 / 总资产不高于 20%。

之后仍按点时总市值从小到大选择 20 只。不得根据结果修改阈值、改为分位数、增加
技术指标或只保留某一财务条件。

## 账户口径与顺序门

复用主板微盘的下一交易日开盘、20只、100股整手、佣金、最低佣金、历史印花税、
双边5bp滑点、T+1、涨跌停、停牌、1%成交额容量、退市核销和资金账规则。

- 开发期：2014–2020；
- 独立验证：2021–2023；
- 已知压力期：2024–2026-08。

开发期先与同口径裸主板微盘对照。候选必须年化不低于裸对照5个百分点以上、最大
回撤至少改善10个百分点、至少6/7年为正、买卖执行率均不低于80%、无未解决退出、
资金账误差不超过0.01元，才允许读取独立验证。验证失败则压力期保持未读。

压力期最终目标仍是2024、2025、2026全部为正，且2026截至8月28日收益大于30%。
只有三段全部通过才允许建立模拟账户；否则该财务过滤家族终止。
