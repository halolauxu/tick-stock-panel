# P0 中国商品期货真实合约数据 v3 合同

冻结日期：2026-08-30

## 目标

在已合格的 20 品种连续线与主力映射上，补齐全部 610 个被映射真实合约日线。连续线负责信号，真实合约负责开仓、每日结算、换月、容量和费用。

## 采集与合格门槛

- 对 v2 映射中每个真实合约调用 Tushare `fut_daily`，范围限制在 2014-01-01 至 2020-12-31 以及合约上市/退市区间；
- 保存 OHLC、结算价、成交量、成交额和持仓量，证券日键唯一；
- 活跃行 OHLC 和结算价为正，成交量与持仓非负；
- 主力映射的证券日中至少 99.9% 能匹配同日真实合约行情；
- 主力切换日中至少 99% 同时具有旧合约和新合约行情，用于旧仓平仓和新仓开仓；
- 所有产物原子写入独立研究目录，任一接口请求失败整轮失败。

只有 v3 为 `DATA_QUALIFIED`，才允许冻结保证金、杠杆、趋势和实际合约撮合规则。
