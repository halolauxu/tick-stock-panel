## 1. 结论

**TERMINATE：四个正向业绩预告类别均未通过开发期冻结门槛，不读取 2021–2023 验证收益，不进入账户回测，不计入年化 50% 策略。**

最接近的两个类别确有正均值，但跨年稳定性、收益集中度或公告日聚类显著性不足。负向预告对照也出现正收益，说明样本的年份与市场共同波动占比较大，不能把开发期均值直接解释为业绩预告方向 Alpha。

## 4. 研究裁决

1. 不查看独立验证与压力期收益，避免围绕已知结果重切阈值；
2. 不改变 10 日持有期、不加入市值/行业/技术形态做开发期续命；
3. 保留业绩预告事件账本供组合风险解释，不作为独立开仓引擎；
4. 下一项转向股票回购，重点区分“方案公告”和“已经实施/完成的现金承诺”；
5. 当前严格达标计数仍为 **0 / 5**。
