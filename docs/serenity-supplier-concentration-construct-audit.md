# Serenity 供应集中度构念审计

审计日期：2026-09-03

## 裁决

**原先唯一通过 PDF 64 分硬门的事件是假阳性；修正后硬门事件为 0。**

该事件是 2026-06-12 的鼎龙股份高端晶圆光刻胶订单进展。原结果把
“公司开发核心原材料、推进原材料自主化”评为供应集中度 4 分。这句话只能证明
内部原材料开发，不能证明光刻胶市场只有 1～2 家供应商、独供、市场份额或替代
认证受限。引用虽然能在 PDF 中逐字找到，但引用与被评分构念不一致。

## 新的确定性门禁

供应集中度评分不低于 3 时，至少一条已绑定 PDF 原句必须同时包含：

1. 供应市场主体，例如供应商、厂商、供给、供应来源、市场份额；
2. 稀缺或受限事实，例如独家、唯一、仅有两三家、高度集中、垄断、高份额或
   替代认证困难。

“前五大供应商采购占比”衡量的是公司的上游采购风险，不是该公司所在卡点产品
市场的供给集中度，因此明确禁用。
