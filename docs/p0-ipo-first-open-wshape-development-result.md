# P0 主板 IPO 首次可买开板 W 形：开发期结果

运行日期：2026-08-31。冻结合同见
[开发期合同](p0-ipo-first-open-wshape-contract.md)。本结果只生成 2014-06-16 至
2016-12-31 的信号；2017 年数据仅用于完成 2016 年末信号的冻结退出，验证段和
压力段信号及账户收益均未读取。

## 裁决

**整个“主板 IPO 首次可买开板 W 形”机制族终止，严格达标计数仍为 `0/5`。**

两个预注册方向都不是可投资 Alpha：

- `OPEN_STRENGTH` 20 万账户年化 `-31.80%`、累计 `-61.93%`、最大回撤
  `-77.66%`，完整交易平均净收益 `-2.62%`；
- `OPEN_SELLOFF` 20 万账户年化 `-8.91%`、累计 `-20.99%`、最大回撤
  `-41.06%`，完整交易平均净收益 `-0.73%`，且有 1 个无法用可靠行情完成的退出。

同期全 A 点时等权基准年化 `+53.32%`。强势开板和急跌开板都远低于 50% 目标、
市场基准和风险闸门，因此不读取 2017–2019 验证信号，也不改变 3 个连板、
正负 5%、2 个仓位或 5 日持有期续命。

## 冻结闸门

| 闸门 | 要求 | 强势 | 急跌 |
|---|---:|:---:|:---:|
| 20 万年化净收益 | >50% | 否 | 否 |
| 相对全 A 年化优势 | ≥20pp | 否 | 否 |
| 相对无方向开板对照优势 | ≥15pp | 是 | 是 |
| 最大回撤 | ≥-30% | 否 | 否 |
| 正收益年份 | ≥2 / 3 | 否 | 是 |
| 完整卖出 | ≥40 | 是 | 否 |
| 买入执行率 | ≥90% | 是 | 是 |
| 卖出执行率 | ≥90% | 是 | 是 |
| 未解决退出 | 0 | 是 | 否 |
| 平均完整交易净收益 | ≥2% | 否 | 否 |
| 信号日聚类 t 值 | ≥2.0 | 否 | 否 |
| 最大单年正利润占比 | ≤60% | 否 | 否 |
| 最大资金账误差 | ≤0.01 元 | 是 | 是 |

两个方向虽然比“所有首次开板都买”的极差对照少亏，但这是相对失败策略的改善，
不是正 Alpha。可执行账户证据否定了“首次可买开板后固定持有五日”这一机制族；
后续若研究 IPO，只能从不同经济机制重新预注册，不能围绕本结果调整阈值和持有期。
