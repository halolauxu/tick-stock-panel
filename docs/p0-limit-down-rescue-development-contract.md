# P0-A3 跌停撬板承接开发期合同

状态：冻结

冻结日期：2026-08-30

## 1. 经济机制

10%跌停板会暂时截断价格发现并集中流动性冲击。若一只非风险警示主板股票当日首次触及跌停，却被真实买盘撬开并收盘回到跌停价上方，说明被迫卖盘可能已被吸收；在最早满足 T+1 的窗口里，承接力量可能继续释放。

本研究只检验一个方向：**首次跌停触板、当日明显撬开但仍大幅下跌的股票，次日开盘买入，下一交易日开盘退出。** 它是跌停队列的流动性吸收事件，不等同于普通超跌反转，也不涉及已经失败的涨停追涨或炸板回封。

## 2. 唯一冻结信号

- 开发期固定为 2014-01-01 至 2020-12-31；验证期与压力期暂不读取。
- 只保留沪深主板 `00/60` 股票，点时名称非 ST、`*ST`或退市整理，上市至少 180 个自然日。
- 信号日原始最低价触及当日 10%跌停价；过去 60 个交易日不曾触及跌停。
- 信号日原始收盘价至少高于跌停价 2%，但仍不高于前收盘参考价的 98%，即真实撬开同时仍保留显著冲击。
- 信号日成交额至少 5,000 万元；同一股票 60 个交易日内只可能出现一次信号。
- 不按触板时刻、题材、当日成交额分位、市值、市场状态或次日竞价表现再筛选。

## 3. 成交与费用

- 信号在收盘后形成，下一交易日开盘买入；买入后的下一交易日开盘卖出，严格执行 A 股 T+1。
- 买入遇停牌、行情缺失或开盘涨停即拒绝；卖出遇跌停最多顺延 20 个交易日，仍无法退出记为未解决。
- 单笔名义金额 2 万元，信号日、买入日和卖出日均执行 1%成交额容量约束。
- 买卖各计 2bp 佣金和 5bp 滑点，卖出按历史有效税率计印花税；原始价判断涨跌停，点时复权价计算收益。
- 同期基准为同一入场日全体合格 A 股从开盘到下一交易日开盘的中位数收益。

## 4. 开发晋级门槛

必须同时满足：可成交事件至少 500 个、独立事件日至少 200 天、可交易率至少 90%、基准覆盖至少 99%、2 万元容量可行率至少 95%、未解决退出为 0；平均单笔净收益至少 1.00%、平均市场超额至少 0.75%、事件日聚类超额 t 值至少 2.5、至少 5 个自然年超额为正，且最盈利单一年不贡献超过全部正超额的 50%。

开发期失败即 `TERMINATE`，不得把 60 日改为其他窗口、降低 2%撬板幅度、加入次日竞价过滤或修改持有期。开发通过也只允许冻结账户规则后进入独立验证，不计入年化 50%目标。
