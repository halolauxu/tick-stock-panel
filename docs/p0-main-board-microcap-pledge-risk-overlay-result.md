## 冻结机制与漏斗

重大新增质押定义为非解押公告且本次质押不低于总股本5%。公告后的下一交易日起，
个股禁入126个交易日；系统开关统计过去20个交易日的重大质押公司数，至少积累52周
后，若达到此前52周90%分位且不少于10只，则下周微盘仓位清零。

开发期共1,129个已可用重大事件，形成94,352个“证券×禁入日”；裸微盘82,078条
候选只减少到80,630条。系统开关在359个调仓周中关闭64周，占17.83%。

## 为什么直接终止

主候选同时失败于年化35%、回撤-30%、七年全正和卖出执行率80%四道门。两个诊断
臂也没有出现可独立晋级的效果。按预注册顺序门，验证期和已知压力期保持未读；不得
为了命中2018或2026而修改5%、126日、20日、52周、90%分位或10只阈值。整个冻结
质押风险机制终止。
