## 投资结论

- **P0-A2：DOWNGRADE。** 首板、二板和三板以上的正收益主要发生在信号日收盘到次日开盘，09:30 后才买入已经太晚；延迟 5 分钟入场到 T+1 可卖时点，四类事件在定位期和确认期全部为负。涨停生态不再作为开仓引擎，只保留为市场状态和执行研究信息。
- **P0-B 第一层：CONTINUE。** 全 A 股点时样本确认微盘横截面溢价在验证期和 2024 年以来的压力期仍然存在，且验证期收益随市值十分位基本单调下降。它获得进入“30 万元、20 只股票统一资金账户”研究的资格。
- **尚未得到年化 50% 投资方案。** 当前 P0-B 是最小市值 10% 的等权横截面，不是可实际持有数百只股票的账户；裸因子在压力期最大回撤为 `-39.49%`，2024 和 2026 年绝对收益仍为负。不得把横截面年化直接写入模拟盘或与其他事件收益相加。

## 对总体路线的更新

1. 引擎 A 的“涨停后追涨开仓”路径终止，不进入模拟盘。后续只允许研究可在信号形成前或盘中因果获得的触发，不能使用已实现的隔夜跳空。
2. 引擎 B 进入第二层：30 万元统一资金账户、20 只股票、100 股整数手、真实现金约束、未卖出持仓延续和完整换仓成本。
3. 灾难规避与账户基线分开冻结。先注册只使用前一交易日可见信息的逃生变量，再把 2024 年初保留为一次性压力检验；不允许看完崩盘后调阈值。
4. 第二层必须同时报告绝对年化、最大回撤、最差周、换手率、容量、无法买卖比例和相对全市场超额。若 20 只账户的验证期或压力期年化低于 15%、最大回撤无法压到 25%以内，微盘引擎降级为小仓位补充，不承担组合 50%目标。
5. 引擎 C 仍停留在数据可得性审计。组合分配器只有在至少两个独立引擎通过统一资金账户后才开始，避免用不存在的低相关性做组合算术。
