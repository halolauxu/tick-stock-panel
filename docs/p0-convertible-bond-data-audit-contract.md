# P0-C 可转债 T+0 数据与可执行性审计合同

状态：冻结

冻结日期：2026-08-30

目标：在设计或回测可转债策略前，先确认现有数据是否足以做点时、可成交、含成本的独立验证。数据审计通过不等于策略有效，也不计入 50%策略数量。

## 1. 必查数据链路

1. 可转债历史证券主表：转债代码、正股、上市日、退市日、发行规模和剩余规模；
2. 历史日线：未复权 OHLC、昨收、成交量、成交额、转股价值、转股溢价率和纯债价值；
3. 历史条款事件：转股价变动、强赎、回售、到期和摘牌，且必须有公告日或生效日；
4. 历史分钟：至少 1 分钟或 5 分钟 OHLCV、可靠时间戳和成交额；
5. 交易规则：T+0、最小交易单位、佣金、无印花税、涨跌幅及临停制度的有效日期版本；
6. 容量：20/30/50/100 万元订单占同期成交额比例和冲击成本代理。

## 2. 现场探针

- 只读取服务器已有配置，不输出令牌或敏感字段；
- 分别探测 `cb_basic`、`cb_daily`、转股价变动、赎回条款和历史分钟权限；
- 日线至少抽查多个相隔年份的交易日，输出行数、唯一代码数、重复键和关键字段缺失率；
- 分钟至少对一只当时有效转债抽查一个完整交易日，输出首末时间、行数、重复键和 OHLCV 缺失率；
- 本地存储与远端能力分开报告：接口可取不等于已经落盘。

## 3. 通过与降级

只有日线主表、点时条款和分钟行情都可获得，才允许直接进入 T+0 原型。

- 若日线和点时条款可用、分钟不可用：只允许研究日频双低/轮动，不得声称 T+0。
- 若条款不能点时重建：只能做描述性基线，不能把强赎前已知信息倒填。
- 若只有近期分钟：历史回测降级，冻结规则后以前向模拟为主验证器。
- 若数据需要采购，输出明确的数据项、历史起点、费用和容量价值，再决定是否接入；不能拿股票分钟代替转债分钟。

## 4. 后续策略研究边界

数据审计通过后，先冻结一个不调参的日频双低基线和一个 T+0 机制假设。两者属于同一可转债机制族，参数版本不能重复计数。所有账户以 20 万元独立开始，并运行 30/50/100 万容量阶梯。
