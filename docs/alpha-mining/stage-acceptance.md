## Stage 0：宪章与冻结基线 — PASS

- 实际改动：建立 Charter、需求追踪矩阵、旧系统基线、污染研究登记和二元验收规则。
- 未改动范围：没有追认历史研究为正式结果，没有降低冠军门槛。
- 测试结果：治理文档逐项人工核对，AM-S0-001 至 AM-S0-011 均有证据。
- 页面/运行证据：不以页面或运行状态作为本阶段证据。
- 剩余风险：用户仍可按 Charter 否决自检结论；任何目标变更必须产生新版本。

## Stage 1：页面与物理隔离 — PASS

- 实际改动：新增独立页面、API、任务命名空间、运行目录和默认关闭的功能开关；Alpha 采用可选加载。
- 未改动范围：旧 `/mining` 路由、API 前缀、运行目录和管理器保持原合同。
- 测试结果：`test_isolation.py`、`test_config.py`、`test_manager.py` 及后端全量回归通过。
- 页面/运行证据：`/alpha-mining` 直接刷新与 390px 无横向溢出；`/mining` 原页面与控制项可用，控制台无错误。
- 剩余风险：尚未部署到线上实例；当前结论只对本工作区代码成立。

## Stage 2：引擎注册系统 — PASS

- 实际改动：完整四维 Manifest、版本和自动权限契约；实现 Feature/Event Provider 与 Candidate Renderer；注册表自动扫描并冻结。
- 未改动范围：新增引擎无需修改中央编排器；引擎不能直接连接数据供应商。
- 测试结果：动态新增/删除模块、重复 ID、错误版本、单引擎异常、恶意外测访问、恶意供应商导入全部通过。
- 页面/运行证据：API 和页面动态展示 8 个注册引擎与开放扩展插槽。
- 剩余风险：未来新增候选输出类型必须有对应执行器和渲染器，不能只扩 Manifest 字符串。

## Stage 3：PIT 数据与研究时钟 — PASS

- 实际改动：统一 Catalog 管理历史股票池、名称/ST、股本、行业、财务公告和自然事件；非交易日映射到下一决策时点；概念快照强制禁入。
- 未改动范围：没有用当前快照回填历史，没有伪造缺失数据，也没有向 2013 年以前采集。
- 测试结果：上市/退市、名称/ST、股本边界、财务公告前不可见、周末事件映射及缺失失败闭合测试通过。
- 页面/运行证据：浏览器验收启动时，既有数据自愈任务 `ddf02c8f91` 成功修复 5 个近期坏分区，当前本地 Catalog 指纹为 `68b46ac32566c2ac0e4ffd2c25ca0e21dc0b8d09c8f6e5da20b2b1842c9c8a0c`；页面明确列出剩余阻断原因。
- 剩余风险：当前本地数据实例只有 245 个 enriched 分区（2025-08-26 至 2026-08-28），历史股票池/股本/财务/行业/事件仍缺失，因此数据状态是 `DATA_GAP`，不能正式研究。

## Stage 4：标签、特征与不可变账本 — PASS

- 实际改动：生成 1/3/5/10/20/60 日毛/净/残差收益、MFE/MAE、跳空和不可成交风险；实验、候选和结果均 write-once。
- 未改动范围：候选冻结后不能修改参数、特征、成本、股票池或退出规则。
- 测试结果：标签数值、未来边界、合同冲突、事件哈希链篡改、失败试验入账和结果幂等测试通过。
- 页面/运行证据：实验账本和候选证据区展示合同、指纹、逐折、门槛、压力和状态事件。
- 剩余风险：旧的 pre-charter 研究仍仅可作为假设来源，不能迁入正式账本。

## Stage 5：首批发现引擎 — PASS

- 实际改动：实现截面、市场/行业时序、事件序列、网络扩散、财务修订、匹配归因、组合残差、非线性交互 8 类引擎。
- 未改动范围：任何现有策略都不是共同底座；只有组合残差引擎按定义读取策略残差。
- 测试结果：8 个引擎均通过合成机制真阳性测试和随机噪声拒绝测试，并受独立试验预算约束。
- 页面/运行证据：页面列出 8 个引擎、四维坐标、数据要求和当前阻断原因。
- 剩余风险：合成测试只证明引擎能发现已知结构，不证明真实 A 股存在可交易 Alpha。

## Stage 6：公共验证与冠军系统 — PASS

- 实际改动：嵌套发现/内选/外测、拼接 OOS、多重试验惩罚、双倍成本、延迟成交、参数扰动、容量和集中度压力；动态冠军与状态机接入运行链。
- 未改动范围：当前冠军仅在公共比较出现，不进入引擎训练输入。
- 测试结果：压力值不是占位符；延迟信号实际移位；非法状态跳转和未过门槛发布均被拒绝。
- 页面/运行证据：候选证据区展示每项压力结果；冠军挑战区从动态账本读取，不再写死页面比较对象。
- 剩余风险：当前没有合格数据版本，尚无可用于判断这些门槛的真实正式候选。

## Stage 7：完整产品页 — PASS

- 实际改动：形成研究总览、机会地图、数据覆盖、发现引擎、实验账本、候选证据、冠军挑战、前向模拟 8 区。
- 未改动范围：旧 `/mining` 页面和功能继续保留，Alpha 页面没有替换旧页面。
- 测试结果：前端生产构建成功；API 投影和动态引擎列表测试通过。
- 页面/运行证据：桌面宽度与 390×844 窄屏均完成浏览器检查；直接刷新、禁用态和空态正常；无控制台错误。
- 剩余风险：取消/断线恢复以 API 和状态测试覆盖，尚未在长时间真实研究任务中观察。

## Stage 8：前向模拟闭环 — PASS

- 实际改动：研究候选创建独立事件驱动账户，复用冻结 factor-rank 合同、T+1、费用和滑点；计算实际滑点、对账、信号订单闭环和因子衰减。
- 未改动范围：没有用回测成交替代前向成交，没有在漂移后自动调参，没有无成交造收益。
- 测试结果：正向/反向因子衰减、跳过信号、信号订单断链、独立账户合同和零成交收益约束通过。
- 页面/运行证据：前向区显示交易日、成交、滑点、对账、Rank IC、漂移和晋级按钮状态。
- 剩余风险：当前没有真实研究候选，因此系统能力通过不等于存在前向通过的账户。

## Stage 9：冠军晋级 — FAIL

- 实际改动：实现 13 项门槛、动态挑战者、create-only 策略发布、AST 校验、加载校验、失败回滚、不可变发布回执和冠军账本。
- 未改动范围：未发布任何真实策略，未替换当前冠军，未把合成候选写入线上策略池。
- 测试结果：合成挑战者可以走完发布/晋级；任一真实门槛缺失都会阻断。
- 页面/运行证据：当前冠军仍是初始可比基准 `n_day_low_reversal`；没有正式挑战者。
- 剩余风险：AM-S9-001 至 AM-S9-011 无真实证据，阶段结论必须为 `FAIL`；稳定优于冠军的 Alpha 尚未找到。
