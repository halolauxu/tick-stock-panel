# Alpha 挖掘工作台产品契约

版本：`AM-WORKBENCH-v1.1`

状态：`FROZEN / USER-APPROVED`

基线：`AM-CHARTER-v1.0`；旧 `/mining` 页面、API、任务和产物保持独立。

## 1. 唯一产品目标

Alpha 挖掘不是工程状态看板，而是研究工作台。每个研究运行必须把一个可追溯的研究问题转换成以下两种结果之一：

1. 通过独立样本外和压力门槛的冻结候选，以及明确的后续验证动作；
2. 可复用的失败证据、失败类型和下一轮研究建议。

任务完成、引擎完成、冻结候选和找到 Alpha 是四种不同状态。页面不得混用。

发现阶段不使用任何现有策略作为底座或比较基准。首任冠军只通过绝对门槛产生；已有冠军只在候选通过绝对门槛后的公共验证阶段参与比较。

## 2. 核心对象

| 对象 | 稳定标识 | 含义 | 不可变边界 |
|---|---|---|---|
| Alpha 假设 | `hypothesis_id` | 来源、论点、经济机制、预测对象、期限、因子方向/权重和证伪条件 | 创建后不可修改；可产生多次运行 |
| 实验运行 | `run_id` | 一次冻结的数据、特征、引擎、预算、验证和成交合同 | 启动后不可修改 |
| 冻结候选 | `candidate_id` | 因子公式、方向、权重、参数、交易规则和证据 | 任何变更生成新候选 |
| 研究裁决 | 候选状态事件 | 淘汰、继续验证、前向、挑战者或冠军 | 只能由证据状态机推进 |

## 3. 页面布局

页面采用固定双栏工作台，而不是纵向八区状态墙。

- 顶栏：页面名称、当前运行、运行状态、历史运行、候选比较和审计入口。
- 新建研究首屏：可以让当前已配置的 DeepSeek 提出假设、选择内置研究先验、提出人工假设，或选择由失败证据生成的后续假设。
- 左侧固定配置栏：选定假设后冻结预测对象、因子方向/权重和发现引擎；仅允许配置日期、研究强度和成交成本。
- 右侧状态工作区：按当前任务状态显示准备、运行、结果或失败，不同时铺开全部模块。
- 结果工作区标签：`结果总览`、`发现证据`、`样本外`、`市场归因`、`稳健性`、`候选方案`、`前向模拟`、`审计`。

桌面宽度下左栏宽度固定在 320 至 380 像素；窄屏改为上方可折叠配置，不产生水平滚动。

## 4. URL 与恢复契约

| 参数 | 含义 | 行为 |
|---|---|---|
| `run` | 当前实验运行 | 直接打开、刷新或返回页面后恢复同一运行 |
| `view` | 当前结果标签 | 恢复用户最后查看的工作区 |
| `candidate` | 当前候选 | 恢复候选主从详情 |

无效 ID 必须显示中文错误并允许返回最近运行，不能静默切换到其他结果。

## 5. 运行前配置与真实 API 映射

| 产品字段 | 请求或数据来源 | 当前能力 | 阶段 |
|---|---|---|---|

| 因子目录选择 | `/api/backtest/factor/columns` → `factor_names` | API 已有，Alpha 页面未开放选择 | P1 |
| 发现引擎选择与阻断原因 | `/engines`、`/availability` | 已有 | P1 |
| 数据资格与外测窗口 | `/availability` | 已有 | P1 |

## 6. 页面状态机

| 页面状态 | 主工作区必须显示 | 主动作 |
|---|---|---|
| 未选择假设 | DeepSeek/内置先验/人工/失败证据来源、机制、公式、数据资格和阻断原因 | 让 DeepSeek 提出、选择假设或提出我的假设 |
| 已选择假设 | 假设全文、冻结方向/权重、实验合同和数据资格 | 检验这个假设 |
| 排队/运行/取消中 | 阶段时间线、总体进度、逐引擎进度、尝试/候选/异常计数 | 取消并保留证据 |
| 运行失败 | 停止阶段、中文原因、受影响引擎、已保存证据 | 修正配置或复制重试 |
| 完成且零通过 | 结论、候选漏斗、最佳失败候选、失败归因、下一轮建议 | 基于失败创建新研究 |
| 完成且有候选 | 总览、证据、候选主从详情 | 升级验证或前向模拟 |
| 前向中 | 交易日、信号、订单、成交、持仓、滑点、对账、衰减 | 核对并判定 |
| 挑战者/冠军 | 绝对门槛、同口径冠军比较、发布记录 | 显式晋级 |

## 7. 结果语义

### 7.1 结果总览

必须显示本轮一句话结论、研究漏斗、最佳候选、主要失败类型、数据或引擎异常和下一步动作。任务完成不得使用成功色暗示 Alpha 成立。

### 7.2 发现证据

每个发现条目必须显示：中文因子名、公式或定义、方向、来源引擎、机制假设、尝试数、进入内选次数、进入外测次数、训练证据和最终裁决。逐次试验摘要直接展示 IC、ICIR、方向一致率、有效交易日和淘汰原因；完整原始 `trial_ledger` 进入审计视图。

### 7.3 样本外

显示拼接样本外净值、逐折收益与夏普、真实覆盖区间、收益日历和交易数。只有完整覆盖对应周期时才显示近一年和近三个月收益；否则显示“覆盖不足”和缺少的交易日数，绝不显示 `null` 或零值。

### 7.4 市场归因

至少按市场强弱、市场宽度、行业和年份展示收益/交易贡献。历史概念快照不可用时明确显示“缺少 PIT 概念历史”，不得使用当前概念倒填。

### 7.5 稳健性

显示双倍成本、延迟成交、参数扰动、容量、个股/行业/年份集中度。每项必须显示实际值、门槛和裁决。

### 7.6 候选方案

候选使用左侧列表、右侧详情。详情必须说明因子、经济机制、打分、买卖时钟、费用、持仓、完整样本外、压力测试、适用市场、失败门槛和状态事件。

## 8. 零候选和失败闭环

失败必须归入以下一种或多种类型：

- `signal_invalid`：训练或内选没有稳定关系；
- `oos_decay`：训练有效但样本外衰减；
- `regime_dependency`：只在单一市场状态有效；
- `execution_cost`：费用、换手或延迟后失效；
- `capacity_concentration`：容量或集中度不合格；
- `insufficient_coverage`：周期或数据覆盖不足；
- `engine_or_data_error`：引擎异常或数据门禁失败。

页面根据冻结证据生成下一轮建议，必须明确“保留什么、改变什么、为什么改变”。用户确认后以新运行提交；不得修改旧运行或自动调参。

## 9. 机会地图

机会地图是可操作的覆盖矩阵，不是四列枚举：

- 行为信息域；列为收益机制；
- 单元格显示可用引擎、历史尝试、冻结候选、通过、证伪、阻断和空白数量；
- 点击单元格过滤发现证据并预选下一轮研究范围；
- 未实现方向保持扩展插槽，不伪装为已有能力。

## 10. P0-P6 二元门禁

| 阶段 | 范围 | PASS 条件 |
|---|---|---|
| P0 | 本产品契约、字段、状态、API 和验收映射 | 所有可见字段有真实来源；所有缺口明确归属后续阶段 |
| P1 | 工作台骨架与 URL 恢复 | 加载、空、错、禁用、刷新和窄屏全部可用；旧 `/mining` 无回归 |
| P2 | 真实运行进度 | 至少一次真实运行展示阶段、逐引擎、预算、异常并可刷新重连 |
| P3 | 完整结果工作区 | 发现、样本外、市场归因、稳健性和候选均来自真实结果，无裸 JSON/英文内部状态/伪指标 |
| P4 | 失败研究闭环 | 零通过运行可解释失败并以显式差异创建新运行，旧证据不变 |
| P5 | 候选生命周期 | 严格验证、前向、挑战者和动态冠军均由状态机门控，无法绕过 |
| P6 | 假设研究闭环 | DeepSeek、内置先验、人工和失败证据均可形成持久化假设；AI 输出必须经过可用因子校验且不得读取样本外答案；至少一条真实假设完成冻结、运行、裁决和下一轮假设回流 |

前一阶段未 PASS，不得宣称后一阶段完成。越级存在的后端能力只能标为已有原型。
