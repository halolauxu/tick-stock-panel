# Alpha Mining Charter

版本：`AM-CHARTER-v1.0`

状态：`ACTIVE / USER-DIRECTED-EXECUTION`

冻结范围：目标、研究边界、状态定义、阶段顺序和验收门槛。未经用户明确确认，不得修改。

## 1. 唯一长期目标

建立一个能够持续发现、证伪并前向验证 A 股可交易 Alpha 的系统。只有候选在相同资金、股票池、成交时钟、费用、滑点、容量和风险口径下，通过全部历史样本外门槛、压力测试及前向模拟，并稳定优于当期冠军，才算目标完成。

新增页面、任务成功、测试通过、候选数量或某个窗口收益为正，均不代表找到 Alpha。

## 2. 不可变研究原则

1. 任何现有策略都不是必选底座；发现引擎必须允许从完整合格股票池独立发现收益机制。
2. 当前冠军只参与公共验证阶段的同窗比较，不得限制发现空间或进入引擎训练输入。
3. 历史范围固定使用现有 2013 年至当前的可用数据，不以“行情覆盖不足”为由继续向前取数。
4. 正式收益必须使用点时数据、A 股 T+1 约束、信号后可成交价格、佣金、印花税、滑点、涨跌停和停牌约束。
5. 当前快照不得回填历史。无法证明历史时点可见的数据必须失败闭合，不能降级为近似数据。
6. 研究失败是正式产物，必须进入试验预算和证据链；不得删除失败后重新包装同一假设。
7. 发现引擎是开放注册体系。首批八类引擎不是 A 股 Alpha 的封闭分类，未来新增信息域、机制、方法和预测对象不应修改中央编排器。
8. 候选冻结后不得修改。新参数、新特征、新股票池、新成本或新退出逻辑必须形成新候选和新实验。

## 3. Alpha 分类坐标

每个发现引擎和候选必须同时声明四个维度：

- 信息来源：价格成交、市场风格、行业概念、财务、公告事件、微观结构、资金供需、文本、跨资产、相对价值或策略残差等。
- 收益机制：趋势、均值回归、信息迟滞、预期差、流动性补偿、风险溢价、行为偏差、制度约束、扩散轮动或执行优势等。
- 发现方法：截面、时序、事件、事件序列、匹配归因、异常检测、规则搜索、非线性学习、残差互补、文本和知识图谱等。
- 预测对象：个股/板块净收益、概率与幅度、MFE/MAE、跳空及不可成交风险、适用状态或组合收益/回撤/相关性。

分类坐标用于检查研究覆盖，不是限制未来引擎的枚举表。

## 4. 完成状态

| 状态 | 唯一定义 |
|---|---|
| 工程原型 | 局部链路可运行，但尚未通过所属阶段全部硬验收。不得表述为工程完成。 |
| 工程完成 | 阶段0至阶段8的代码、数据、页面、隔离、审计和前向链路全部通过各自二元验收。 |
| 数据合格 | 指定数据集通过覆盖、PIT、发布时间、完整性和未来信息审计。只能对具体数据版本成立。 |
| 研究完成 | 一个预注册假设被完整验证或证伪，所有试验和结果可追溯。研究完成不等于策略有效。 |
| 研究候选 | 冻结候选通过全部历史样本外和压力门槛，但尚未通过前向模拟。 |
| 前向通过 | 冻结候选达到预注册观察天数、交易样本、成交一致性和漂移门槛。 |
| 目标完成 | 前向通过的挑战者满足全部晋级门槛并成为新冠军。 |

任何缺失证据只能记为 `PENDING` 或 `FAILED`，不得推断为通过。

## 5. 阶段门禁

开发严格按阶段0至阶段9推进：

1. 前一阶段未通过，不得开始下一阶段的新开发。
2. 已经越级存在的代码统一标记为 `UNACCEPTED_PROTOTYPE`，不能反向证明阶段通过。
3. 每阶段只允许 `PASS` 或 `FAIL`；只要一个硬验收项未通过，阶段结论就是 `FAIL`。
4. 每阶段固定交付五项：实际改动、未改动范围、测试结果、页面或运行证据、剩余风险。
5. 每项需求必须具有固定编号，并在代码、测试和验收证据中引用。
6. 阶段通过必须有逐项证据和二元结论；用户可在最终验收时否决任何自检结论。

## 6. 系统隔离边界

原 `/mining` 完整保留。Alpha 系统使用独立页面、API、任务命名空间、运行产物、候选证据库、自动配置和发布状态机。允许共享的仅是标准化数据仓库、回测矩阵、交易撮合、成本模型、纯展示组件及重任务资源限流。

Alpha 功能被关闭、删除、损坏或运行失败时，旧挖掘页面、API、任务、候选、调度和发布必须继续工作。

## 7. 冠军晋级硬门槛

候选必须同时满足：

1. 13年拼接样本外净收益高于当期冠军；
2. Sharpe 不低于 `max(0.8, 冠军 + 0.20)`；
3. 最大回撤不超过25%，且不劣于冠军；
4. 至少65%的半年窗口为正；
5. 至少60%的半年窗口跑赢冠军；
6. 最近一年跑赢冠军；
7. 最近三个月绝对净收益为正；
8. 两倍成本后仍为正；
9. 延迟成交和参数扰动后不整体失效；
10. 收益不集中于单一年份、股票、行业或少数交易；
11. 前向模拟通过。

任意一项不通过或缺证据，都没有新冠军，系统继续研究其他机制。

## 8. 变更控制

目标、冠军、门槛、数据口径、历史范围、股票池、成交时钟、隔离边界、阶段顺序和完成定义属于受控字段。任何调整必须：

1. 提交带编号的变更请求；
2. 说明原因及对既有证据的影响；
3. 获得用户明确确认；
4. 生成新宪章版本；
5. 将受影响的旧结果标记为不可比较或重新验证。

AI、开发者、测试或运行结果均无权自行降低门槛。
