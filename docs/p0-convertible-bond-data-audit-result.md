## 2. 研究边界

当前可以安全推进两件事：

1. 回补日线、分钟和主表，先做一个月端到端数据质量与成交容量证明；
2. 研究日内平仓的 T+0 机制。因为日内不留隔夜仓，强赎事件风险显著低于跨日轮动，但仍要将异常停牌、缺失行情和临停作为不可成交事件。

当前不能做的事：

- 不能用 `cb_basic` 的“最新转股价”回填历史；
- 不能用未来摘牌日提前剔除债券；
- 不能把缺少强赎公告的跨日双低轮动称为严格点时验证；
- 不能把股票分钟的单位转换直接套给转债；本次实测确认转债分钟成交量已经是“手”，不应再除以 100。

## 3. 外部权限事实

Tushare 官方文档说明：

- `cb_daily` 提供可转债日线、成交量/成交额、纯债价值、转股价值和溢价率，需至少 2,000 积分；
- `cb_call` 提供公告日、强赎状态和赎回日，需 5,000 积分；
- `cb_price_chg` 是单独权限接口，不能仅靠积分解锁。
